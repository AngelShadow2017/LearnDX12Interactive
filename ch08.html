本章学习目标（Objectives）

  • 理解基本的"光-表面交互"模型；
  • 掌握法向量与变换法线的正确姿势；
  • 实现环境光、漫反射、镜面反射的局部光照模型（朗伯/Phong/Blinn-Phong）；
  • 实现平行光、点光源、聚光灯三种光源；
  • 在 HLSL 中写出完整光照着色器。

有了光照，画面才从"色块"变成"世界"。这是全书画面质量起飞的一章。

8.1 光与材质的交互（Light and Material Interaction）

光射到表面：一部分被吸收，一部分被反射（反射色进入眼睛 → 我们看到的颜色）。物体"红"是因为它吸收绿蓝、反射红。物理上光在墙后会遮挡（阴影），但本章用局部光照：只算"表面直接被光照到的效果"，不管遮挡与间接光——快，但真实感有限（阴影留到第 11/20 章，间接光留到第 21 章）。

8.2 法向量（Normal Vectors）

光照计算的核心输入是法线：垂直于表面的向量，决定"这个面朝向哪个方向、接收多少光"。

  • 面法线：垂直于三角形平面的单位向量；
  • 顶点法线：顶点处的近似法线 = 共享该顶点的各面法线的平均（面积加权更平滑），这就是"平滑着色"的秘密；
  • 变换法线的坑：用非均匀缩放变换物体时，直接用同一矩阵变换法线会"掰弯"它。正确做法是用法线的逆转置矩阵（(A⁻¹)ᵀ）。书中给出完整证明——这是面试高频题。

8.4 朗伯余弦定律（Lambert's Cosine Law）

同样一束光，垂直照射地面时单位面积得到的光最多；斜射时摊到更大面积、变暗。照度 ∝ cosθ（θ 是光方向与法线的夹角）：

f(θ) = max(cosθ, 0) = max(L·n, 0)

点积为负（光从背面来）取 0——用 max 截断。

8.5 漫反射光（Diffuse Lighting）

粗糙表面把光向四面八方均匀散射（纸张、粉笔墙），因此漫反射强度与观察位置无关，只与入射角有关：

cdiffuse = max(L·n, 0) · BL ⊗ md

其中 BL 是入射光颜色，md 是材质漫反射色，⊗ 表示按分量相乘。

8.6 环境光（Ambient Lighting）

局部模型里背光面全黑太假。环境光是"作弊项"：给所有地方加一个常量底色，近似天空/墙面的间接光：

cambient = AL ⊗ md

更高级的替代：第 21 章的环境光遮蔽（AO）会在角落里削弱这一项。

8.7 镜面光（Specular Lighting）

光滑表面（金属、水面）把光主要沿反射方向集中反射——高光。Phong 模型：计算反射向量 r = reflect(−L, n)，强度 ∝ (r·v)p（v 是指向眼睛的向量，p 是光泽度指数，越大高光越小越锐）。Blinn-Phong 优化：用半程向量 h = normalize(L + v) 代替 r，用 (n·h)p，更便宜更接近实测。现代版还带菲涅尔效应（掠射角反射更强，Schlick 近似）与粗糙度参数（书中给出粗糙度函数曲线图）。

8.9 实现材质（Implementing Materials）

材质 = 一组参数：环境色、漫反射色、镜面色 + 光泽度。物体不同部位可用不同材质组（书中"汽车 5 个材质组"的例子）。实现上把 Material 结构通过常量缓冲传入着色器。

8.10–8.12 三种光源

  • 平行光（Directional Light）：只有方向没有位置（太阳）。方向即光传播方向，强度不随距离衰减——最便宜；
  • 点光源（Point Light）：有位置，向四周发光，随距离衰减（书中的三段式衰减：全强度 → 线性衰减到 0 → 熄灭；也可用 1/d² 物理式）；
  • 聚光灯（Spotlight）：有位置有朝向，只在锥角内发光。用半角 φmax 与 L·d 的余弦比较，还可加内外锥过渡更平滑。

三者对"朗伯 + 镜面"计算的接口一致，只是"求 L（指向光源向量）"和"衰减因子"不同。

8.13 光照实现（Lighting Implementation）

三个 demo 着色器（方向光/点光/聚光）+ Lights demo 场景：一个格网山丘 + 立方柱列 + 骷髅头。着色器结构：VS 变换到世界空间并输出法线/位置；PS 里逐光源算 ambient+diffuse+specular 求和，最后 tone 映射 + gamma 校正（书中 demo 附带 SimpleToneMap）。

// Blinn-Phong 光照核心（简化自书中代码）
float shininess = gRoughness1 * 256.0f;
float3 h = normalize(L + V);            // 半程向量
float spec = pow(max(dot(N, h), 0.0f), shininess);
float diff = max(dot(N, L), 0.0f);
float3 lit = ambient + diff * diffuseColor + spec * specColor;
💡 读完做实验：把 shininess 调大调小看高光变化；关掉环境光看背光面；把点光源衰减调快。

本章小结

  • 颜色 = 环境光 + 漫反射 + 镜面光之和；漫反射服从朗伯余弦定律（L·n）。
  • 镜面高光用 Blinn-Phong 半程向量；光泽度 p 控制高光锐度；菲涅尔让掠射角更亮。
  • 法线变换必须用逆转置矩阵；顶点法线由面法线平均。
  • 平行光/点光/聚光的区别在"求 L"与"距离/角度衰减"。
