<h2>12.1 编写几何着色器</h2>

<p>几何着色器（GS）是一个能<b>扩展或丢弃图元</b>的可编程阶段：它以整个图元为输入，可以输出 0 个、1 个或多个顶点。本书也在曲面细分阶段讲如何生成更细的几何；这里聚焦 GS 逐图元处理的方式。</p>

<Figure src="images/Fig12-1.jpg" alt="把一个三角形细分成四个等大三角形" figureNumber="图 12.1" caption="把一个三角形细分成四个等大三角形：三个新顶点是各边中点。" />

<CodeSample
  title="几何着色器的声明骨架"
  language="hlsl"
  code={`struct VertexOut { float3 PosW : POSITION; float2 SizeW : SIZE; };
struct GeoOut    { float4 PosH : SV_POSITION; float3 PosW : POSITION;
                   float3 NormalW : NORMAL; float2 Tex : TEXCOORD;
                   uint PrimID : SV_PrimitiveID; };

// maxvertexcount 必须给出：它决定一次调用最多能输出多少个顶点
[maxvertexcount(4)]
void GS(point VertexOut gin[1],
        uint primID : SV_PrimitiveID,
        inout TriangleStream<GeoOut> stream)
{
    // 用相机的三个轴构造广告牌的局部坐标系
    float3 up    = float3(0.0f, 1.0f, 0.0f);
    float3 look  = gEyePosW - gin[0].PosW;
    look.y = 0.0f;  // 让树保持竖直
    look = normalize(look);
    float3 right = normalize(cross(up, look));

    float halfW = 0.5f * gin[0].SizeW.x;
    float halfH = 0.5f * gin[0].SizeW.y;
    float4 v[4];
    v[0] = float4(gin[0].PosW + halfW * right - halfH * up, 1.0f);
    v[1] = float4(gin[0].PosW + halfW * right + halfH * up, 1.0f);
    v[2] = float4(gin[0].PosW - halfW * right - halfH * up, 1.0f);
    v[3] = float4(gin[0].PosW - halfW * right + halfH * up, 1.0f);

    GeoOut gout;
    [unroll]
    for (int i = 0; i < 4; ++i)
    {
        gout.PosH  = mul(v[i], gViewProj);
        gout.PosW  = v[i].xyz;
        gout.NormalW = look;
        gout.PrimID = primID;
        stream.Append(gout);
    }
}`}
  input={<>顶点着色器输出 <code>point</code> 图元（拓扑为 <code>D3D_PRIMITIVE_TOPOLOGY_POINTLIST</code>）。</>}
  keyLines={[
    { code: '[maxvertexcount(4)]', note: '必须给出的一次调用输出上限；输出超过它会被硬件截断，症状是图形缺角。' },
    { code: 'look.y = 0.0f;', note: '把视线压平，树才不会因为相机俯仰而倒下来。' },
    { code: 'stream.Append(gout)', note: '逐个追加顶点；要开始新的条带时调用 stream.RestartStrip()。' },
    { code: 'uint primID : SV_PrimitiveID', note: '图元 ID，常用来从纹理数组里选资源（图 12.7—12.9）。' },
  ]}
  output={<>图 12.6：几何着色器把一个点扩成一个 quad，图 12.5 是树广告牌演示的截图。</>}
  pitfalls={[
    '忘记写 maxvertexcount：着色器编译失败，错误信息往往指向 Append 那几行。',
    '输出顶点数超过 maxvertexcount：图形被静默截断，很难从画面反推原因。',
    '把 GS 当成性能优化手段：它打破了后变换顶点缓存，多数硬件上并不便宜。',
  ]}
/>

<h2>12.3 纹理数组</h2>

<p>纹理数组（<code>Texture2DArray</code>）把多张同尺寸、同格式、mip 级数一致的纹理放进一个资源，用一个索引选择（图 12.7）。这样一次绘制就能画出多种树。</p>

</div>

<Callout tone="tip">
  <b>数组索引怎么来</b>
  <p>常见做法是把索引放在顶点数据里，或者用 GS 拿到的 <code>SV_PrimitiveID</code>。这样同一个绘制调用里的不同实例就能取到不同贴图。</p>
</Callout>
</section>

<section className="lesson-section" id="s124">
<h2>12.4 Alpha-to-Coverage</h2>

<p>A2C 把像素着色器输出的 alpha 转换成 MSAA 的<b>子采样覆盖掩码</b>：alpha 越大，通常覆盖的样本越多。样本掩码是离散的，具体映射取决于 MSAA 样本数和实现；例如 4× MSAA 下 alpha = 0.5 可近似对应 4 个样本中的 2 个。这样能平滑树叶等镂空边缘，也不需要为这些裁切纹理做透明混合排序。</p>

<Callout tone="warning">
  <b>必须同时启用 MSAA</b>
  <p>A2C 单独开启没有任何效果——没有多个子采样点，就谈不上覆盖率。这是这一节最容易记错的一条。</p>
</Callout>
</section>

<section className="lesson-section" id="s125">
<h2>本章小结</h2>

<ul>
  <li>GS 以整个图元为输入，可以增删顶点；<code>maxvertexcount</code> 必须声明。</li>
  <li>广告牌是 GS 的典型应用：CPU 提交一个点，GPU 扩成朝向相机的 quad。</li>
  <li>纹理数组用一个索引在多张贴图之间选择，常配合 <code>SV_PrimitiveID</code> 或顶点属性。</li>
  <li>A2C 把 alpha 转成 MSAA 覆盖率，能避免 alpha 混合的排序问题，但<b>必须同时启用 MSAA</b>。</li>
  <li>GS 会打破后变换顶点缓存，在多数硬件上并不便宜；能用实例化解决的场景优先用实例化。</li>
</ul>
