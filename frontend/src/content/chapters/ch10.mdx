<section className="lesson-section lesson-section--intro" id="s101">
<h2>10.1 混合方程</h2>

<p>混合发生在输出合并阶段：源色（当前像素着色器的输出）与目标色（后台缓冲里已有的值）按一个方程组合。</p>

<div className="math-block">C = F<sub>src</sub> ⊗ C<sub>src</sub> &nbsp;op&nbsp; F<sub>dst</sub> ⊗ C<sub>dst</sub><small>⊗ 表示逐分量相乘，op 默认是 ADD</small></div>

<Figure src="images/Fig10-1.jpg" alt="半透明的水面——透过它能看见水下的东西" figureNumber="图 10.1" caption="半透明的水面——透过它能看见水下的东西。" />

<Callout tone="note">
  <b>混合是逐通道做的</b>
  <p>RGB 和 alpha 可以各用一套因子与运算（<code>SrcBlendAlpha</code> / <code>DestBlendAlpha</code> / <code>BlendOpAlpha</code>）。大多数情况下两者设成一样即可。</p>
</Callout>

<section className="lesson-section" id="s103">
<h2>10.3 混合因子</h2>

<p>常用的因子有：</p>

<ul>
  <li><b>ZERO / ONE</b>：0 与 1，用来完全忽略或完全保留某一侧。</li>
  <li><b>SRC_ALPHA / INV_SRC_ALPHA</b>：源 alpha 与它的补，标准 alpha 混合的两块拼图。</li>
  <li><b>SRC_COLOR / INV_SRC_COLOR</b>：用源色本身当权重，常用来做乘法混合。</li>
  <li><b>DEST_ALPHA / INV_DEST_ALPHA</b>：用目标 alpha 当权重。</li>
</ul>

<p>运算（<code>BlendOp</code>）除了默认的 ADD，还有 SUBTRACT、REV_SUBTRACT、MIN、MAX。</p>
</section>

<section className="lesson-section" id="s104">
<h2>10.4 混合状态</h2>

<p>D3D12 里混合状态是 PSO 的一部分（<code>D3D12_BLEND_DESC</code>），没有独立的「设置混合」调用。每个渲染目标槽位可以各配一套，还可以用 <code>BlendEnable</code> 开关。</p>

<Callout tone="tip">
  <b>一个常见技巧</b>
  <p>图 10.2 提到的「不写颜色」（<code>RenderTargetWriteMask = 0</code>）只写深度/模板，常用来先「占住深度」再做后续绘制。</p>
</Callout>
</section>

<section className="lesson-section" id="s106">
<h2>10.6 Alpha 通道</h2>

<p>alpha 不只是「透明度」：它可以是镂空掩码、材质遮罩或任意自定义数据。关键区别在于你拿它做什么——参与混合方程，还是拿去 clip。</p>
</section>

<section className="lesson-section" id="s107">
<h2>10.7 裁剪像素</h2>

<p><code>clip(x)</code> 在 HLSL 里丢弃当前像素（x &lt; 0 时）。对铁丝网这类带镂空的纹理（图 10.6），它比混合更合适：不需要排序，也不会出现排序错误。</p>

<Figure src="images/Fig10-6.jpg" alt="铁丝网纹理及其 alpha 通道" figureNumber="图 10.6" caption="铁丝网纹理及其 alpha 通道：alpha 为黑的像素会被 clip 丢弃，形成镂空。" />

<CodeSample
  title="像素着色器里的 clip"
  language="hlsl"
  code={`float4 PS(VertexOut pin) : SV_Target
{
    float4 diffuseAlbedo = gDiffuseMap.Sample(gsamAnisotropicWrap, pin.TexC);

    // alpha 低于阈值的像素直接丢弃，不再参与后续任何阶段
    clip(diffuseAlbedo.a - 0.1f);

    // 剩下的和正常光照流程一样
    float3 lit = ...;
    return float4(lit, diffuseAlbedo.a);
}`}
  input={<>一张带 alpha 通道的纹理与一个各向异性 wrap 采样器。</>}
  keyLines={[
    { code: 'clip(diffuseAlbedo.a - 0.1f)', note: '参数小于 0 就丢弃该像素。阈值可以调，太小会留下黑边，太大会把细节剪掉。' },
    { code: 'gsamAnisotropicWrap', note: '静态采样器名；各向异性 + wrap 是地表/围墙类纹理的常见搭配。' },
  ]}
  output={<>网孔处完全透明，能看到后面的物体；边缘是硬边，没有半透明过渡。</>}
  pitfalls={[
    'clip 阈值定得太低：纹理边缘残留黑边（因为 alpha 是插值出来的中间值）。',
    '把需要半透明过渡的效果用 clip 实现：边缘会变成锯齿，需要配合 MSAA 或 alpha-to-coverage。',
    'clip 之后仍然开启混合：两者混用会让结果难以预测，先想清楚要哪种效果。',
  ]}
/>
</section>

<h2>10.8 雾效</h2>

<p>雾效与混合无关：它按像素到眼睛的距离，把受光颜色插值到雾色（图 10.9、10.10）。</p>

<section className="lesson-section" id="s109">
<h2>本章小结</h2>

<ul>
  <li>混合方程 C = F<sub>src</sub> ⊗ C<sub>src</sub> op F<sub>dst</sub> ⊗ C<sub>dst</sub>，逐通道执行；RGB 与 alpha 可分开设置。</li>
  <li>标准 alpha 混合是 <code>SRC_ALPHA</code> + <code>INV_SRC_ALPHA</code> + ADD。</li>
  <li>混合状态属于 PSO；可以用 <code>RenderTargetWriteMask = 0</code> 只写深度不写颜色。</li>
  <li>加法混合常用在火焰与光效；这类效果通常关闭深度写入但保留深度测试。</li>
  <li><code>clip</code> 直接丢弃像素，适合镂空纹理，不需要排序、没有排序错误，但边缘是硬边。</li>
  <li>雾效按距离把颜色插值到雾色，与混合是完全不同的机制。</li>
</ul>
