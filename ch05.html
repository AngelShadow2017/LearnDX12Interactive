第二部分 · Direct3D 基础

本章学习目标（Objectives）

  • 理解 3D 视觉效果的要素：透视、遮挡、光照、阴影等；
  • 掌握用三角形网格表示 3D 物体；
  • 理解颜色表示（RGB / 32 位色）；
  • 核心：完整理解渲染管线每个阶段做什么，这是理解 DX12 全书的关键章。

5.1 3D 视觉的原理（The 3D Illusion）

屏幕是 2D 的，如何产生 3D 感？书中归纳四个手段：①透视投影——近大远小、平行线汇聚于消失点；②遮挡——前面的物体挡住后面的（深度缓冲实现）；③光照与着色——球体有明暗才像 3D（不然就是圆盘）；④阴影——投影暗示光源位置和物体高度。后续章节逐一实现：投影（本章）、深度（第 4 章）、光照（第 8 章）、阴影（第 11、20 章）。

5.2 模型表示

物体用三角形网格近似（triangulated mesh）。三角形是"最小平面"：三点必共面、顶点少、可以插值。建模软件导出网格 → 顶点数组 + 索引数组 → 交给显卡绘制。

5.3 基本颜色（Basic Computer Color）

显示器由红绿蓝三色发光单元组成，用 (r, g, b) 混出所有颜色；每通道 8 位（0–255）共 32 位（多 8 位 alpha 透明度）。shader 里颜色用 [0,1] 浮点表示。加色混合：红+绿=黄等。可对照 Windows 的 ChooseColor 对话框理解 RGB 分量。向量可表示颜色，因此颜色也能做"加减乘"（第 10 章混合会用到）。

5.4 渲染管线总览（Overview of the Rendering Pipeline）

给定 3D 场景和一台虚拟相机，渲染管线负责生成 2D 图像。管线是一串可编程（着色器）+ 可配置（状态）的阶段：

输入装配(IA) → 顶点着色器(VS) → 曲面细分(HS/TS/DS) → 几何着色器(GS) → 裁剪 → 光栅化(RS) → 像素着色器(PS) → 输出合并(OM)

每个阶段处理完传给下一个；着色器阶段（VS/HS/DS/GS/PS）是你用 HLSL 写的 GPU 程序，其余是固定功能但可配置。下面逐个过。

5.5 输入装配阶段（Input Assembler, IA）

从内存读顶点/索引数据，把它们组装成图元（primitive）：点、线、三角形。

图元拓扑（Primitive Topology）

  • PointList / LineStrip / LineList；
  • TriangleStrip：3 顶点后每加 1 顶点拼出新三角形，省顶点；
  • TriangleList：每 3 个顶点一个三角形，最常用（书里 demo 全用它）；
  • 带邻接（adjacency）的拓扑：给 GS 提供相邻图元信息（第 12 章）。

索引（Indices）

一个矩形要 2 个三角形、6 个顶点，但 4 个角落点被重复定义。索引缓冲允许顶点只存一次、按索引重复引用（去重 + 共享），既省内存又能让顶点缓存命中。四边形/八边形等都要三角化。

顶点着色前的两个矩阵概念

本地空间 → 世界空间：物体顶点先相对自身原点建模，用世界矩阵（第 3 章的 SRT）放到世界中；世界空间 → 视角空间（相机空间）：把世界坐标转换成"相机在原点、朝 −z 看"的坐标——用的就是相机变换的逆矩阵。书中用四足机器人/城堡的例子图解本地 vs 世界坐标。

5.6 顶点着色器阶段（Vertex Shader, VS）

每个顶点跑一次的 GPU 程序，功能：①变换（world → view → projection）；②逐顶点效果（如顶点光照、动画）。不可创建/销毁顶点，输入 1 输出 1。

投影：局部空间 → 齐次裁剪空间（Homogeneous Clip Space）

投影矩阵把视锥（frustum，相机能看到的四棱台）映射到规范体 [−1,1]³。顶点被变换到 4D 齐次坐标 (x, y, z, w)，其中 w = 视空间 z——透视除法（x/w, y/w, z/w）发生在光栅化阶段。近处物体放大、远处缩小正是 w 除法的结果（书中用相似三角形推导透视投影矩阵，并给出 FOV、宽高比、近远平面的参数化公式）。

视口（Viewport）与剪刀矩形

裁剪空间 [-1,1] 经视口变换映射到后台缓冲子矩形；剪刀矩形额外限制像素写入区域（遮罩式裁剪，效率高）。

5.7/5.8 曲面细分与几何着色器（本章只需知道存在）

曲面细分（Tessellation）：把低模在 GPU 上动态细分出更多三角形（第 14 章详解）。几何着色器（GS）：以整个图元为输入，可增删顶点、生成新图元（第 12 章）。本章先建立管线全景即可。

5.9 裁剪（Clipping）

完全在视锥外的图元直接丢弃；跨越边界的图元被切分，只保留体内部分（三角形可能被裁成四边形再三角化）。裁剪在齐次空间用 −w ≤ x ≤ w 等不等式判定。这解释了为何叫"裁剪空间"。

5.10 光栅化阶段（Rasterization Stage）

  • 背面剔除（Backface Culling）：每个三角形有朝向（绕序）。从相机看背面朝上的三角形直接丢弃——封闭物体一半三角形省掉。约定：左手系中顺时针绕序 = 正面（可配置）。投影前判断即可（用叉积/面积的符号）。
  • 透视校正插值：顶点属性（颜色、法线、UV）跨三角形插值时必须考虑透视，否则贴图会歪。
  • 视口变换 + 透视除法发生在进入像素处理之前。

5.11 像素着色器阶段（Pixel Shader, PS）

对每个像素片元（fragment）执行，输入是插值后的顶点属性（世界坐标、法线、UV……），输出该像素颜色。逐像素光照（第 8 章）、贴图采样（第 9 章）都在这里做。本书所有"画面好看"的逻辑基本都在 PS。

5.12 输出合并阶段（Output Merger, OM）

PS 输出的像素要经过"合并考试"才能写到后台缓冲：深度测试（离相机近的才能写，配合深度缓冲）、模板测试（第 11 章）、混合（与已有颜色按公式混合，第 10 章半透明）。后台缓冲被整个场景的所有像素"竞争"写入，最终显示。

本章小结

  • 3D 感 = 透视 + 遮挡 + 光照 + 阴影；物体 = 三角形网格。
  • 颜色 = RGB（[0,1] 浮点 / 8 位通道）。
  • 管线记忆口诀：IA 组装 → VS 变换 → （细分/GS）→ 裁剪 → 光栅化（剔除+插值）→ PS 上色 → OM 合并。
  • 三个空间：本地 → 世界（世界矩阵）→ 视角（视图矩阵）→ 齐次裁剪（投影矩阵）。
  • 透视除法 w、背面绕序、透视校正插值——这三个细节最常被新手忽略。
