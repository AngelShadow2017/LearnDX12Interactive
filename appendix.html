附录 A · Windows 编程入门（Introduction to Windows Programming）

为没用过 Win32 API 的读者准备的最小教程。全书示例都基于同一套窗口框架，读这一节你就能看懂示例代码里 main 函数之外的部分。

核心内容

  • 事件驱动模型：Windows 程序靠"消息（Message）"驱动——鼠标移动、按键、窗口重绘都是消息。窗口过程（Window Procedure，WndProc）收到消息后做响应。
  • 标准五步：定义窗口类（WNDCLASS）→ 注册（RegisterClass）→ 创建窗口（CreateWindow）→ 显示更新（ShowWindow / UpdateWindow）→ 消息循环（GetMessage / DispatchMessage）。
  • 消息循环与游戏循环的区别：GetMessage 会"挂起"程序等消息，游戏需要持续的帧循环，因此书中改用 PeekMessage + 计时器的游戏循环（第 4 章详解）。
  • 常用消息：WM_CREATE（创建时）、WM_PAINT（重绘）、WM_DESTROY（销毁，PostQuitMessage）、WM_LBUTTONDOWN 等。
// 书中窗口框架的骨架（简化）
WNDCLASS wc; wc.lpfnWndProc = MainWndProc; // 绑定窗口过程
RegisterClass(&wc);
HWND mhMainWnd = CreateWindow(...);
ShowWindow(...);
MSG msg = {0};
while(msg.message != WM_QUIT) {
  if(PeekMessage(&msg, 0, 0, 0, PM_REMOVE)) { DispatchMessage(&msg); }
  else { // 没消息 → 游戏循环：更新+绘制 }
}

附录 B · HLSL 语言参考（High-Level Shader Language Reference）

HLSL 是 DirectX 的着色器语言，用来编写顶点着色器、像素着色器、几何着色器、计算着色器等。这个附录是一本"速查手册"。

要点清单

  • 变量类型：float/int/bool 及向量、矩阵类型 float2/3/4、float4x4；矩阵初始化按行书写。
  • 语义（Semantics）：告诉 GPU 数据"是什么"——POSITION、NORMAL、TEXCOORD、COLOR；输出流语义以 SV_ 开头（如 SV_POSITION 系统值）。
  • 结构体传数据：顶点数据用结构体在阶段间传递，常量缓冲用 cbuffer 声明（寄存器 b）、纹理 t、采样器 s。
  • 常用内置函数：normalize、dot、cross、mul（矩阵乘）、lerp、saturate、reflect、abs、pow、exp、floor、ceil、clamp。
  • 函数修饰：无修饰 = 普通函数；可定义 VS/PS 入口函数由运行时编译并绑定到 PSO。
// 典型常量缓冲（第 6 章 Box 示例的着色器）
cbuffer cbPerObject : register(b0) {
  float4x4 gWorldViewProj;
};
struct VertexIn {
  float3 PosL  : POSITION;
  float4 Color : COLOR;
};
struct VertexOut {
  float4 PosH  : SV_POSITION;   // 齐次裁剪空间坐标
  float4 Color : COLOR;
};

附录 C · 解析几何（Some Analytic Geometry）

游戏编程常用的几何公式集，配合第 16 章（包围体）与第 17 章（拾取）使用：

  • 三角形：由三点 v0、v1、v2 定义；两边向量叉积可得法向量；用重心坐标表示三角形内的点，p = v0 + u(v1 - v0) + w(v2 - v0)，且 u,w≥0、u+w≤1。
  • 射线：p(t) = p0 + t·u（t≥0），常用于拾取与阴影测试。
  • 平面：n·p + d = 0；三点可确定平面；点到平面距离 = n·p + d（|n|=1 时）。
  • 圆柱：轴心线、半径与高度范围定义。
  • 球：球心 c 与半径 r，|p − c| = r；点在球内判定 |p − c| ≤ r。
  • AABB（轴对齐包围盒）：用最小点 vmin 与最大点 vmax 表示，碰撞/剔除测试快。
  • OBB（有向包围盒）：带朝向的盒子，用三个轴向 + 三个半径 + 中心表示。
💡 用途：视锥剔除（第 16 章）要判断包围体是否在 6 个裁剪平面之内；拾取（第 17 章）要算射线与三角形的交点——都建立在这些公式上。
