<h3>32 位颜色</h3>

<p>一个 32 位颜色里 alpha、红、绿、蓝各占 1 字节，通常打包成一个 <code>XMCOLOR</code>（ARGB）。着色器里用的是 0—1 的浮点四元组。</p>

<h3>视图空间</h3>

<p>把顶点从世界空间变换到<b>视图空间</b>（以相机为原点）。构造相机坐标系需要相机位置、目标点和世界「上」方向。</p>

<div className="figure-pair">
  <Figure src="images/Fig5-19.jpg" alt="把顶点从世界空间转换到相对相机的视图空间" figureNumber="图 5.19" caption="把顶点从世界空间坐标转换为相对相机（视角）空间的坐标。" />
  <Figure src="images/Fig5-20.jpg" alt="由相机位置、目标点与世界上方向构造相机坐标系" figureNumber="图 5.20" caption="由相机位置、目标点与世界「上」方向构造相机坐标系。" />
</div>

<Callout tone="warning">
  <b>约定校正：相机朝向与深度范围</b>
  <p>在 Direct3D 的<b>左手系</b>里，视图空间的相机看向 <b>+z</b>：<code>XMMatrixLookAtLH</code> 构造出的 z 轴是 focus − eye。因此「在相机前方」意味着 z &gt; 0。</p>
  <p>投影之后，D3D12 的裁剪条件是 <b>0 ≤ z ≤ w</b>（不是 −w ≤ z ≤ w）。透视除法后归一化深度落在 <b>[0, 1]</b>，近平面为 0、远平面为 1。这与 OpenGL 的 [−1, 1] 不同，本站早期版本沿用了错误表述，这里更正。</p>
</Callout>

<h3>投影与齐次裁剪空间</h3>

<p>视锥定义了相机「看得到」的体积（图 5.21）。投影矩阵把它映射成一个规整的盒子，同时完成透视缩小（图 5.22）。</p>

<section className="lesson-section" id="s511">
<h2>5.11 像素着色器阶段</h2>

<p>PS 对每个像素片段执行一次，输入是插值后的顶点属性，输出一个颜色值。它也可以直接 <code>discard</code> 把片段丢掉——第 10 章的 alpha 裁剪就用这个。</p>

<Callout tone="tip">
  <b>顶点着色器 vs 像素着色器</b>
  <p>VS 每个顶点跑一次，PS 每个像素片段跑一次。屏幕上通常有大量像素，所以 PS 往往是性能瓶颈；把可以预计算的东西挪到 VS 里是常见优化。</p>
</Callout>
</section>

<section className="lesson-section" id="s512">
<h2>5.12 输出合并阶段</h2>

<p>OM 是最后一道关：它做深度测试、模板测试和混合，决定这个像素最终是否写入后台缓冲、写入什么值。</p>

<ul>
  <li><b>深度测试：</b>比当前深度小的才通过（默认 <code>DepthFunc = LESS</code>）。</li>
  <li><b>模板测试：</b>用模板缓冲限制绘制区域（第 11 章）。</li>
  <li><b>混合：</b>把源色与目标色按混合方程组合（第 10 章）。</li>
</ul>

<Callout tone="note">
  <b>顺序很重要</b>
  <p>模板测试 → 深度测试 → 混合。任何一个环节判定为「丢弃」，后面的混合就不会发生。</p>
</Callout>
</section>

<section className="lesson-section" id="s513">
<h2>本章小结</h2>

<ul>
  <li>3D 错觉来自线性透视、近大远小、遮挡、光照和阴影这几条线索；实体用三角形网格近似。</li>
  <li>管线顺序：IA → VS →（曲面细分 / GS）→ 裁剪 → RS → PS → OM。记每站的输入输出比背名字有用。</li>
  <li>IA 按拓扑组装图元，索引让顶点能被复用。</li>
  <li>空间链路：本地 → 世界 → 视图 → 齐次裁剪空间 →（透视除法）NDC → 屏幕。</li>
  <li><b>约定校正：</b>左手系下相机看向 +z；D3D12 裁剪条件是 0 ≤ z ≤ w，归一化深度范围 [0, 1]。</li>
  <li>裁剪逐图元进行，与视锥相交的图元会被切割并生成新顶点。</li>
  <li>绕序在光栅化阶段判定，改矩阵或相机不改变绕序；D3D12 默认剔除背面、顺时针为正面。</li>
  <li>PS 每个像素片段执行一次，可以 discard；OM 做模板 → 深度 → 混合，决定最终写入。</li>
</ul>
