<section className="lesson-section lesson-section--intro" id="s141">
<h2>14.1 细分图元类型</h2>

<p>曲面细分把「一个粗糙的 patch」在 GPU 上切成细密的三角形。它分三个阶段（图 14.1）：<b>外壳着色器</b>（Hull Shader）→ <b>镶嵌器</b>（Tessellator，固定功能）→ <b>域着色器</b>（Domain Shader）。</p>

<Figure src="images/Fig14-1.jpg" alt="渲染管线中曲面细分三个阶段的示意" figureNumber="图 14.1" caption="渲染管线中曲面细分三个阶段的示意。" />

<p>绘制时要使用 patch 拓扑，并指定每个 patch 有几个控制点。常用的枚举是 <code>D3D_PRIMITIVE_TOPOLOGY_3_CONTROL_POINT_PATCHLIST</code>（三角形 patch）与 <code>D3D_PRIMITIVE_TOPOLOGY_4_CONTROL_POINT_PATCHLIST</code>（四边形 patch）；PSO 的 <code>PrimitiveTopologyType</code> 也要设为 <code>D3D12_PRIMITIVE_TOPOLOGY_TYPE_PATCH</code>。</p>
</section>

<section className="lesson-section" id="s142">
<h2>14.2 外壳着色器</h2>

<p>HS 分两部分：</p>

<ul>
  <li><b>控制点函数</b>：每个输出控制点执行一次，可以变换控制点或透传。</li>
  <li><b>Patch 常量函数</b>：每个 patch 执行一次，输出<b>细分因子</b>——这是控制 LOD 的地方。</li>
</ul>

<CodeSample
  title="Patch 常量函数：按距离算细分因子"
  language="hlsl"
  code={`struct PatchTess { float EdgeTess[4] : SV_TessFactor;
                   float InsideTess[2] : SV_InsideTessFactor; };

PatchTess ConstantHS(InputPatch<VertexOut, 4> patch, uint patchID : SV_PrimitiveID)
{
    PatchTess pt;
    float3 center = 0.25f * (patch[0].PosW + patch[1].PosW
                           + patch[2].PosW + patch[3].PosW);
    float d = distance(center, gEyePosW);

    // 距离越近细分越密：d <= 20 时为 64，d >= 100 时为 0（剔除 patch）
    float tess = 64.0f * saturate((100.0f - d) / (100.0f - 20.0f));

    pt.EdgeTess[0] = tess; pt.EdgeTess[1] = tess;
    pt.EdgeTess[2] = tess; pt.EdgeTess[3] = tess;
    pt.InsideTess[0] = tess; pt.InsideTess[1] = tess;
    return pt;
}`}
  input={<>四个控制点与相机世界坐标 <code>gEyePosW</code>。</>}
  keyLines={[
    { code: 'SV_TessFactor / SV_InsideTessFactor', note: '边缘因子控制各条边，内部因子控制内部区域。相邻 patch 的共享边必须采用一致的边缘因子；内部因子不要求与边缘因子相等。' },
    { code: '64.0f * saturate((100 − d) / 80)', note: '把距离映射到 0—64：d≤20 时取 64，d≥100 时取 0 并剔除该 patch。' },
    { code: 'distance(center, gEyePosW)', note: '常用 patch 中心到相机的距离；也可以用包围盒最近点，更精确。' },
  ]}
  output={<>图 14.5：离相机越近网格越密、越远越疏。</>}
  pitfalls={[
    '相邻 patch 对同一条共享边给出不同的边缘因子：边界顶点不一致，会出现裂缝。内部因子与边缘因子不同本身不会造成这类裂缝。',
    '因子设成 0：该 patch 会被整个剔除（这正是剔除看不见的 patch 的手段，但也可能是 bug）。',
    '忘记设置 3 或 4 控制点 patch 拓扑，或把 PSO 的拓扑类型漏设为 PATCH：细分阶段不会按预期工作。',
  ]}
/>

<Callout tone="note">
  <b>跨 patch 的共享边要单独保证一致</b>
  <p>上面的距离 LOD 按每个 patch 的中心算一个值，便于说明原理。真实相邻 patch 不能各自独立给共享边不同的细分因子，否则边界顶点不一致会产生裂缝；可用共享边端点/中点等相同数据计算两侧的边缘因子。</p>
</Callout>

<h2>14.3 镶嵌器</h2>

<section className="lesson-section" id="s144">
<h2>14.4 域着色器</h2>

<p>域着色器为镶嵌器生成的<b>每一个新顶点</b>执行一次，输入是 <code>SV_DomainLocation</code> 给出的 (u, v)（或三角形 patch 的 (u, v, w)）。它在这里把规范域坐标映射回真实位置——比如采样高度图、求值贝塞尔曲面。</p>

<Figure src="images/Fig14-4.jpg" alt="4 控制点的 quad patch 在规范 uv 空间细分成 16 个顶点" figureNumber="图 14.4" caption="4 控制点的 quad patch 在规范 uv 空间细分成 16 个顶点。" />

<section className="lesson-section" id="s145">
<h2>14.5 四边形细分</h2>

<p>把上一节的机制用在四边形网格上，就得到最实用的效果：距离 LOD（图 14.5）。离相机近的 patch 因子大、网格密；远的因子小、网格疏。</p>

<Figure src="images/Fig14-5.jpg" alt="离相机越近的网格细分越密" figureNumber="图 14.5" caption="离相机越近的网格细分越密（动态 LOD）。" />

<Callout tone="tip">
  <b>什么时候值得用</b>
  <p>曲面细分的价值在于「用少量顶点换来大量细节」，并且能按距离连续变化。但它也有固定开销：patch 数量很多时，HS/DS 的调用次数本身就会成为瓶颈。先用它做地形、水面这类大面积曲面最划算。</p>
</Callout>
</section>

<section className="lesson-section" id="s147">
<h2>本章小结</h2>

<ul>
  <li>曲面细分三阶段：HS（输出控制点与因子）→ 镶嵌器（按因子切分，固定功能）→ DS（算每个新顶点的位置）。</li>
  <li>输入拓扑使用 <code>D3D_PRIMITIVE_TOPOLOGY_3_CONTROL_POINT_PATCHLIST</code> 或 <code>D3D_PRIMITIVE_TOPOLOGY_4_CONTROL_POINT_PATCHLIST</code>；PSO 的拓扑类型设为 <code>D3D12_PRIMITIVE_TOPOLOGY_TYPE_PATCH</code>。</li>
  <li>相邻 patch 的共享边缘因子要一致，避免边界裂缝；内部因子控制 patch 内部细分，不必等于边缘因子。因子为 0 会剔除整个 patch。</li>
  <li>距离 LOD 是它最有价值的应用：patch 中心到相机的距离映射到因子范围。</li>
  <li>三次贝塞尔只保证经过首末控制点；4 × 4 控制点网格构成贝塞尔曲面。</li>
</ul>
