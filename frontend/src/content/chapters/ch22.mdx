<section className="lesson-section" id="s222">
<h2>22.2 四元数代数</h2>

<p>四元数 <b>q = (x, y, z, w)</b> 定义在四维空间上，单位四元数有 3 个自由度，正好够描述 3D 旋转。</p>

<p>其中 i² = j² = k² = ijk = −1，乘法规则可以在图 22.5 那样的示意里建立直觉：<b>虚数部分之间的乘法等价于叉积</b>，实数部分与虚数部分相乘等价于点积。</p>

<p>平行四边形恒等式是四元数最重要的性质：</p>

<div className="math-block">‖q₁ ⊗ q₂‖ = ‖q₁‖ ‖q₂‖<small>范数可乘，这正是它不丢长度、不退化的原因</small></div>
</section>

<section className="lesson-section" id="s223">
<h2>22.3 单位四元数与旋转</h2>

<p><b>单位四元数</b>（‖q‖ = 1）与「绕单位轴 n 转 θ」一一对应：</p>

<div className="math-block">q = (n·sin(θ/2), cos(θ/2))<small>前三个分量是 (x, y, z)，第四个是 w；n 必须是单位向量</small></div>

<p>在精确算术中，单位四元数相乘仍为单位四元数；实际浮点计算会有舍入误差，长时间复合旋转时仍可能需要重新归一化。四元数不会遇到欧拉角参数化的万向锁。</p>

<QuaternionRotationActivity />

<Callout tone="note">
  <b>四元数乘法不可交换</b>
  <p><code>q₁ · q₂ ≠ q₂ · q₁</code>（对应旋转的复合顺序不同），但满足结合律，可以像矩阵一样预乘。</p>
</Callout>
</section>

<section className="lesson-section" id="s224">
<h2>22.4 四元数插值</h2>

<p>插值是四元数最有价值的用途。三种常见做法（图 22.6—22.8）：</p>

<ul>
  <li><b>LERP + 归一化</b>：最简单，但球面上并非匀速（图 22.8）。</li>
  <li><b>SLERP</b>：沿单位球面的大圆匀速走，是标准做法（图 22.6）。</li>
  <li><b>SQUAD</b>：需要控制点，能保证角速度连续，代价更高。</li>
</ul>

<h3>q 与 −q：短弧问题</h3>

<p>最容易忽略的一点是：<b>q 与 −q 表示同一个旋转</b>（图 22.9）。R<sub>q</sub> 绕 n 转 θ，而 R<sub>−q</sub> 绕 −n 转 2π−θ，结果完全一样。</p>

<p>但插值路径不同（图 22.10）：从 a 到 b 可能走 10° 的短弧，也可能走 350° 的长弧——后者看起来就像「转了一大圈再回来」。解决办法就是先判断点积：</p>

<div className="figure-pair">
  <Figure src="images/Fig22-9.jpg" alt="Rq 绕 n 转 θ，R−q 绕 −n 转 2π−θ" figureNumber="图 22.9" caption="Rq 绕 n 转 θ，R−q 绕 −n 转 2π−θ：q 与 −q 表示同一旋转。" />
  <Figure src="images/Fig22-10.jpg" alt="从 a 插值到 b 走大弧，先把 b 取负则走短弧" figureNumber="图 22.10" caption="从 a 插值到 b 走大弧 θ1；先把 b 取负则走短弧——最短路径修正。" />
</div>

<section className="lesson-section" id="s225">
<h2>22.5 DirectXMath 四元数函数</h2>

<ul>
  <li><code>XMQuaternionRotationAxis(axis, angle)</code>：绕轴旋转。</li>
  <li><code>XMQuaternionMultiply</code>：复合两个旋转四元数；<code>XMVector3Rotate</code>：用四元数旋转 3D 向量。</li>
  <li><code>XMQuaternionSlerp</code>：对单位四元数做球面插值，并处理短弧选择。</li>
  <li><code>XMQuaternionRotationMatrix</code> 与 <code>XMMatrixRotationQuaternion</code>：矩阵与四元数互转；<code>XMQuaternionNormalize</code>：归一化。</li>
</ul>

<Callout tone="warning">
  <b>自己写插值时别忘了短弧判断</b>
  <p><code>XMQuaternionSlerp</code> 已经处理好了；但如果自己实现 LERP/SLERP，漏掉 <code>a·b &lt; 0</code> 的处理就会出现「转一大圈」的动画 bug。</p>
</Callout>
</section>

<section className="lesson-section" id="s227">
<h2>本章小结</h2>

<ul>
  <li>复数乘法 = 平面内旋转 + 缩放；四元数把它推广到 3D。</li>
  <li>单位四元数 q = (n·sin(θ/2), cos(θ/2)) 与「绕单位轴 n 转 θ」一一对应。</li>
  <li>平行四边形恒等式保证 ‖q‖ 不漂移，所以没有万向锁；代价是四元数乘法不可交换。</li>
  <li>SLERP 沿球面大圆匀速插值；LERP 归一化简单但速度不均。</li>
  <li><b>q 与 −q 表示同一旋转</b>：插值前必须判断点积并取反，否则会走长弧。</li>
</ul>
