<section className="lesson-section" id="s192">
<h2>19.2 法线图</h2>

<p>法线图和普通颜色贴图一样是 RGB 纹理，只是每个像素存的是一条<b>法线</b>。它存的是三个 [−1, 1] 的分量，采样后要做 <code>2·c − 1</code> 的解包。</p>

<p>关键点：这条法线是<b>相对表面</b>的，不是相对世界坐标系的（图 19.3）。</p>

<Figure src="images/Fig19-3.jpg" alt="法线图中的法线相对切线空间存储" figureNumber="图 19.3" caption="法线图中的法线相对切线空间（T 为 u 轴、B 为 v 轴、N 为法线）存储。" />

<Callout tone="tip">
  <b>一个额外通道</b>
  <p>法线贴图的 alpha 通道常被复用来存「光泽度」之类的遮罩（图 19.7），这样一张贴图就能同时控制凹凸与反光。</p>
</Callout>

<Figure src="images/Fig19-7.jpg" alt="地砖法线图的 alpha 通道表示光泽度" figureNumber="图 19.7" caption="地砖法线图的 alpha 通道：alpha 值表示该处的光泽度。" />
</section>

<section className="lesson-section" id="s193">
<h2>19.3 纹理/切线空间</h2>

<p>为了让「相对表面」变得明确，每个顶点要带一组<b>切线空间</b>基向量（图 19.4）：</p>

<ul>
  <li><b>T（切线）</b>：沿纹理 u 方向；</li>
  <li><b>B（双切线）</b>：沿纹理 v 方向，<code>B = cross(N, T) × handedness</code>；</li>
  <li><b>N（法线）</b>：几何法线。</li>
</ul>

  <Figure src="images/Fig19-5.jpg" alt="盒子每个面的切线空间都不同" figureNumber="图 19.5" caption="盒子每个面的切线空间都不同。" />
</div>
</section>

<section className="lesson-section" id="s194">
<h2>19.4 顶点切线空间</h2>

<p>由于每个面的切线空间都不同（图 19.5），切线必须作为<b>逐顶点属性</b>存进顶点缓冲。顶点着色器里用 <code>float3x3(T, B, N)</code> 打包传给像素着色器。</p>

<Callout tone="warning">
  <b>手性（handedness）</b>
  <p>镜像 UV 会让 TBN 变成左手系，着色结果会左右颠倒。用 <code>cross(N, T)</code> 的 z 分量的符号判断手性，必要时翻转 B 或整个基。</p>
</Callout>
</section>

<section className="lesson-section" id="s195">
<h2>19.5 切线空间与物体空间</h2>

<p>贴图法线 (x, y, z) 还原到世界空间就是一次线性组合：<b>n = T·x + B·y + N·z</b>，再归一化。</p>

<p>图 19.6 说明 T 里平行于 N 的分量必须先减掉（正交化），否则组合出来的法线不严格垂直于表面。</p>

<Figure src="images/Fig19-6.jpg" alt="由 ‖N‖=1 得 projN(T)=(T·N)N，正交化示意" figureNumber="图 19.6" caption="由 ‖N‖=1 得 projN(T)=(T·N)N；T−projN(T) 是 T 中垂直于 N 的分量（正交化）。" />

<h2>19.6 法线贴图着色器代码</h2>

<CodeSample
  title="法线贴图着色器"
  language="hlsl"
  code={`// 顶点着色器：把 TBN 打包传下去
out VSOut
{
    float3 PosW  : POSITION;
    float2 TexC  : TEXCOORD;
    float3 Normal : NORMAL;
    float3 TangentW : TANGENT;
    float3 BitangentW : BINORMAL;
}

// 像素着色器：采样 → 解包 → 缩放 → 组合
float4 PS(VSOut pin) : SV_Target
{
    float3 n = normalize(pin.Normal);
    float3 t = normalize(pin.TangentW);
    float3 b = cross(n, t);

    float3 packedN = gNormalMap.Sample(gSampler, pin.TexC).rgb;
    packedN = 2.0f * packedN - 1.0f;          // 解包到 [-1, 1]
    packedN.xy *= gNormalMapStrength;         // 法线强度

    n = normalize(t * packedN.x + b * packedN.y + n * packedN.z);
    // ... 用 n 继续第 8 章的光照
}`}
  input={<>一张切线空间法线贴图，以及逐顶点的 N / T。</>}
  keyLines={[
    { code: '2.0f * packedN - 1.0f', note: '解包：[0,1] → [−1,1]。漏掉这步，法线全都偏向 (0,0,1)。' },
    { code: 'packedN.xy *= gNormalMapStrength', note: '强度为 0 等于关闭；过大时高光会「浮」在表面上。' },
    { code: 't * packedN.x + b * packedN.y + n * packedN.z', note: '用 TBN 基把切线空间法线还原到世界空间，最后归一化。' },
  ]}
  output={<>几何完全没变，但表面出现凹凸细节，高光也随之碎裂。</>}
  pitfalls={[
    '忘记解包 2·c−1：凹凸方向整体偏移，画面像「贴反了」。',
    '法线强度开得过大：高光与真实几何对不上，看起来像浮在表面。',
    'T 没有逐顶点传入：整个网格共用一条切线，弯曲表面上会明显出错。',

<section className="lesson-section" id="s197">
<h2>本章小结</h2>

<ul>
  <li>法线贴图不移动任何顶点，只扰动光照使用的法线——用一张 2D 纹理换来源表面细节。</li>
  <li>贴图里存的是切线空间法线，必须先 <code>2·c−1</code> 解包。</li>
  <li>每个顶点要带切线 T（沿 u），双切线 B = cross(N, T) × handedness。</li>
  <li>还原到世界空间：<code>n = normalize(T·x + B·y + N·z)</code>；T 需先正交化。</li>
  <li>手性标志处理镜像 UV；法线强度要适中，过大会让高光「浮」在表面上。</li>
</ul>
