  <p>DirectXMath 是<b>行主序 + 行向量</b>（<code>v · M</code>），HLSL 默认按<b>列主序</b>存放矩阵。所以从 C++ 上传矩阵时通常要 <code>XMMatrixTranspose</code>，或者在 HLSL 里显式声明 <code>row_major</code>。忘了这一步，立方体会歪。</p>

<h3>解析几何速查</h3>

<p>下面几条在本书各章都会用到。</p>

$$
u\ge 0,\qquad v\ge 0,\qquad u+v\le 1,\qquad t>0
$$

<p className="math-note">Möller–Trumbore 射线与三角形相交测试（第 17 章）：u、v 是三角形内的重心坐标，t 是沿射线方向的距离参数。</p>

<ul>
  <li><b>点积判角度</b>：<code>dot(n, l)</code> 的符号告诉你光源在正面还是背面；<code>max(..., 0)</code> 截断（朗伯余弦定律，第 8 章）。</li>
  <li><b>平面方程</b>：法线 n 通过点 p₀，则 <code>n · (x − p₀) = 0</code>，即 <code>n · x + d = 0</code>，其中 d = −n · p₀。视锥的六个平面就是从视投影矩阵的行列组合出来的（第 16 章）。</li>
  <li><b>点到平面的有符号距离</b>：<code>n · p + d</code>（n 为单位法线）。这就是包围球与视锥判定的全部（第 16 章）。</li>
  <li><b>反射</b>：<code>r = d − 2(d · n)n</code>（第 8、18 章）。</li>
  <li><b>齐次裁剪</b>：D3D12 的裁剪条件是 <code>0 ≤ z ≤ w</code> 且 <code>−w ≤ x, y ≤ w</code>（第 5 章）。</li>
  <li><b>旋转的两种表示</b>：欧拉角（会有万向锁）↔ 单位四元数（无漂移），转换公式见第 22 章。</li>
</ul>

<h2>附录 E · 延伸阅读</h2>

<p>下面是原书参考文献里最值得先读的几条，以及今天更实用的官方资料。书末的完整文献列表涵盖从图形学经典论文到各家 GPU 厂商的技术演示。</p>

<h3>先读这几条</h3>

<ul>
  <li><b>Angel, Interactive Computer Graphics: A Top-Down Approach with OpenGL</b>——图形学基础最经典的一本。第 1—3 章的数学部分讲得比本书更细。</li>
  <li><b>Blinn, Jim Blinn's Corner</b>——光栅化、阴影、纹理等主题的经典专栏合集，适合按需查阅。</li>
  <li><b>Blinn &amp; Newell, "Clipping using Homogeneous Coordinates"（SIGGRAPH '78）</b>——齐次裁剪的原始论文，第 5 章裁剪部分的理论出处。</li>
  <li><b>de Berg 等, Computational Geometry</b>——第 17 章的射线求交与其他几何算法想深入时的标准参考。</li>
</ul>
