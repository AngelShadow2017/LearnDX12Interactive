<section className="lesson-section lesson-section--intro" id="s151">
<h2>15.1 视图变换回顾</h2>

<p>视图变换把世界坐标变成「相机视角下的坐标」。在 D3D 的左手系里，相机被放到<b>原点</b>，并且沿 <b>+z</b> 方向观察（图 15.1）。</p>

<Figure src="images/Fig15-1.jpg" alt="相机坐标系：相机位于原点、朝 +z 看" figureNumber="图 15.1" caption="相机坐标系：相对自身坐标系，相机位于原点、朝 +z 看（坐标轴为右/上/前）。" />

<CodeSample
  title="从眼点、注视点和上方向构造观察矩阵"
  language="cpp"
  code={`auto gView = XMMatrixLookAtLH(eye, focus, up);`}
/>

$$
\begin{aligned}
\mathbf{z} &= \operatorname{normalize}(\mathbf{focus}-\mathbf{eye}) \\
\mathbf{x} &= \operatorname{normalize}(\mathbf{up}\times\mathbf{z}) \\
\mathbf{y} &= \mathbf{z}\times\mathbf{x}
\end{aligned}
$$

<p className="math-note">平移项由眼点在三个相机轴上的投影决定：$(-\mathbf{eye}\cdot\mathbf{x},-\mathbf{eye}\cdot\mathbf{y},-\mathbf{eye}\cdot\mathbf{z})$。</p>

<Callout tone="tip">
  <b>矩阵里能读出相机轴</b>
  <p>在行向量约定下，视图矩阵左上角的 3×3 旋转块，其三列分别是相机 right / up / look 轴在世界坐标中的方向分量；相机世界矩阵（视图矩阵的逆）的对应三行则直接存着这三条轴。想调试时，可以把这些轴画出来。</p>
</Callout>
</section>

<section className="lesson-section" id="s152">
<h2>15.2 Camera 类</h2>

<p>相机类维护位置（<code>mPosition</code>）、一组基轴（<code>mRight</code>、<code>mUp</code>、<code>mLook</code>）和镜头参数。<code>Walk</code>/<code>Strafe</code> 沿 look/right 轴平移；<code>Pitch</code> 绕 right 轴旋转 look/up；<code>RotateY</code> 绕世界 y 轴旋转三条基轴。</p>

<p>相机直接维护位置与基轴，而不是反复累乘整块相机变换矩阵。多次旋转后，<code>UpdateViewMatrix</code> 会重新正交化三条基轴，再据此构造视图矩阵。</p>

<CodeSample
  title="旋转基轴并重新正交化"
  language="cpp"
  code={`void Camera::Pitch(float angle)
{
    XMMATRIX R = XMMatrixRotationAxis(XMLoadFloat3(&mRight), angle);
    XMStoreFloat3(&mUp, XMVector3TransformNormal(XMLoadFloat3(&mUp), R));
    XMStoreFloat3(&mLook, XMVector3TransformNormal(XMLoadFloat3(&mLook), R));
}

void Camera::RotateY(float angle)
{
    XMMATRIX R = XMMatrixRotationY(angle);
    XMStoreFloat3(&mRight, XMVector3TransformNormal(XMLoadFloat3(&mRight), R));
    XMStoreFloat3(&mUp, XMVector3TransformNormal(XMLoadFloat3(&mUp), R));
    XMStoreFloat3(&mLook, XMVector3TransformNormal(XMLoadFloat3(&mLook), R));
}

void Camera::Reorthonormalize()
{
    XMVECTOR R = XMLoadFloat3(&mRight);
    XMVECTOR U = XMLoadFloat3(&mUp);
    XMVECTOR L = XMVector3Normalize(XMLoadFloat3(&mLook));
    U = XMVector3Normalize(XMVector3Cross(L, R));
    R = XMVector3Cross(U, L);
    XMStoreFloat3(&mRight, R);
    XMStoreFloat3(&mUp, U);
    XMStoreFloat3(&mLook, L);
}`}
  input={<>相机当前位置以及单位正交基轴 <code>mRight</code>、<code>mUp</code>、<code>mLook</code>。</>}
  keyLines={[
    { code: 'XMMatrixRotationAxis(mRight, angle)', note: '俯仰绕相机 right 轴旋转 look 与 up。' },
    { code: 'XMMatrixRotationY(angle)', note: '偏航绕世界 y 轴旋转三条相机基轴。' },
    { code: 'U = normalize(cross(L, R))', note: '旋转误差会慢慢累积；重建正交基可把三条轴恢复为单位且互相垂直。' },
  ]}
  output={<>每帧得到一份 <code>gView</code>，与投影矩阵相乘就是视投影矩阵。</>}
  pitfalls={[
    '多次旋转后不重新正交化：浮点误差会让基轴逐渐不再垂直或单位化。',
    '忘记归一化 mLook：移动速度会随时间变化。',
    '若应用希望采用传统 FPS 视角，可在输入层限制俯仰角；书中的相机类直接应用 Pitch，不做这个限制。越过竖直方向后相机会倒转，但基轴和视图矩阵仍然有效。',
  ]}
/>

<section className="lesson-section" id="s153">
<h2>15.3 关键方法实现</h2>

<ul>
  <li><code>GetView()</code>/<code>GetProj()</code>：读取缓存的视图/投影矩阵；相机位置或朝向变化后调用 <code>UpdateViewMatrix()</code> 更新视图。</li>
  <li><code>Walk(d)</code>：沿 mLook 前进 d。</li>
  <li><code>Strafe(d)</code>：沿 mRight 平移 d。</li>
  <li><code>Pitch(angle)</code>/<code>RotateY(angle)</code>：分别绕相机 right 轴和世界 y 轴旋转基轴；<code>SetLens()</code> 设置视锥参数并更新投影矩阵。</li>
</ul>

<Callout tone="warning">
  <b>视图矩阵的逆就是相机世界矩阵</b>
  <p>相机的 right、up、look 轴彼此正交且已归一化，因此可以利用这个结构构造逆矩阵（旋转部分取转置，并正确处理平移）。若手头只有 view 矩阵，也可调用 <code>XMMatrixInverse(nullptr, view)</code>；通用求逆不一定比利用相机基轴更快。拾取等操作会用到相机世界矩阵。</p>
</Callout>
</section>

<section className="lesson-section" id="s155">
<h2>15.5 动态索引</h2>

<p>动态索引让着色器能按数据选择一组独立纹理资源；这种着色器资源数组用法是 Shader Model 5.1 引入的。与 <code>Texture2DArray</code> 不同，<code>Texture2D</code> 资源数组中的纹理可以有不同尺寸和格式。书中的示例把材质数据放进 <code>StructuredBuffer&lt;MaterialData&gt;</code>，每个绘制项的物体常量带 <code>MaterialIndex</code>；材质再用 <code>DiffuseMapIndex</code> 指向纹理描述符数组中的贴图。材质缓冲和纹理数组每帧绑定一次，绘制项仍各自选择对应材质。</p>
