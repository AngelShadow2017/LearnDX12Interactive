<section className="lesson-section lesson-section--intro" id="s31">
<h2>3.1 线性变换</h2>

<p>这一章回答两个问题：怎样用矩阵表达「缩放 / 旋转 / 平移」，以及怎样在<b>变换物体</b>和<b>变换坐标系</b>之间来回切换。</p>

<h3>定义</h3>

<p>变换 τ 是线性的，当且仅当它满足：</p>

$$
\begin{aligned}
\tau(\mathbf{u}+\mathbf{v}) &= \tau(\mathbf{u})+\tau(\mathbf{v}) \\
\tau(k\mathbf{u}) &= k\tau(\mathbf{u})
\end{aligned}
$$

<p>线性变换不改变原点、不产生平移，它把一个向量映射成另一个向量。缩放和旋转都是线性变换。</p>

<h3>缩放</h3>

<p>缩放矩阵把各坐标分量分别乘以缩放因子：</p>

$$
S=\begin{bmatrix}
s_x&0&0\\
0&s_y&0\\
0&0&s_z
\end{bmatrix}
$$

<Callout tone="note">
  <b>旋转矩阵的性质</b>
  <p>旋转矩阵是正交矩阵：它的逆等于它的转置，det = 1，且各列（行）都是单位向量并两两正交。所以旋转一定可逆，而且求逆非常便宜。</p>
</Callout>

<section className="lesson-section" id="s32">
<h2>3.2 仿射变换</h2>

<p>平移不是线性变换（它移动了原点）。把「线性变换 + 平移」合在一起就是<b>仿射变换</b>：</p>

$$
\alpha(\mathbf{u})=\tau(\mathbf{u})+\mathbf{b}
$$

<p>为了让矩阵能表达平移，要引入<b>齐次坐标</b>：给向量加第四个分量 w。w = 1 表示点（会被平移影响），w = 0 表示方向向量（不受平移影响）。</p>

<div className="figure-pair">
  <Figure src="images/Fig3-5.jpg" alt="用位移向量 b 把蚂蚁的位置移动一段距离" figureNumber="图 3.5" caption="用位移向量 b 把蚂蚁的位置移动一段距离。" />
  <Figure src="images/Fig3-6.jpg" alt="沿 x 轴平移 12、沿 y 轴平移 −10" figureNumber="图 3.6" caption="沿 x 轴平移 12、沿 y 轴平移 −10（从 −z 轴方向观察）。" />
</div>

<Callout tone="tip">
  <b>w 分量就是「点 vs 向量」的开关</b>
  <p>用 <code>XMVectorSet(x, y, z, 1)</code> 变换点、<code>XMVectorSet(x, y, z, 0)</code> 变换方向。方向向量用 w = 0 就不会被平移污染——法线、视线方向都属于这一类。</p>
</Callout>

<h3>仿射矩阵每一行的几何含义</h3>

<p>仿射变换用 4 × 4 矩阵表示，配合行向量写成 v · M。关键理解：<b>结果的每一行是原矩阵行向量的线性组合</b>，而最后一行（配合行向量）放的是平移量。</p>

<section className="lesson-section" id="s33">
<h2>3.3 变换的组合</h2>

<p>因为矩阵乘法满足结合律，我们可以把一串变换预先乘成一个矩阵。书里的性能对比很直接：20000 个顶点依次做缩放、旋转、平移，逐步做要 20000 × 3 次向量矩阵乘法；先合成 C = SRT 则只要 20000 次向量矩阵乘法加 2 次矩阵乘法。</p>

<Callout tone="note">
  <b>用一个点检查「先做谁」</b>
  <p>行向量约定下，取点 $p=(1,1)$，先把 x 放大 2 倍，再沿 x 平移 3，结果是 $(5,1)$。矩阵按 $pST$ 相乘；改成 $pTS$ 就是先平移再放大，结果变成 $(8,1)$。同样两步操作，只因顺序不同就落在不同位置。</p>
</Callout>

<Callout tone="warning">
  <b>顺序不能随便换</b>
  <p>结合律成立，交换律不成立。图 3.9 就是证据：先旋转再平移（RT）与先平移再旋转（TR）得到完全不同的结果。</p>
</Callout>

<Figure src="images/Fig3-9.jpg" alt="先旋转再平移与先平移再旋转的对比" figureNumber="图 3.9" caption="(a) 先旋转再平移。(b) 先平移再旋转——顺序不同，结果完全不同。" />

<section className="lesson-section" id="s34">
<h2>3.4 坐标系变换</h2>

<p>100°C 是水相对于摄氏刻度的沸点。同一个温度换成华氏刻度是多少？要做这个换算，需要知道两个刻度之间的关系。</p>

<Callout tone="tip">
  <b>最关键的一句话</b>
  <p>书上强调：<b>坐标系变换中我们不认为几何发生了变化</b>，我们改变的是参考系，于是坐标的表示变了。这和「真的把物体移动／形变」的旋转、平移、缩放是完全不同的两件事。</p>
</Callout>

<Figure src="images/Fig3-10.jpg" alt="同一向量相对不同坐标系坐标不同" figureNumber="图 3.10" caption="同一向量 v 相对不同坐标系的坐标不同：相对 A 为 (x,y)，相对 B 为另一组值。" />

<h3>向量</h3>

<p>设 p 相对 A 的坐标是 (x, y)，A 的基向量是 u、v。从图上直接得到：</p>

$$
\mathbf{p}=x\mathbf{u}+y\mathbf{v}
$$

<p>把等式里每个向量都改用 B 的坐标表示：</p>

$$
\mathbf{p}_B=x\mathbf{u}_B+y\mathbf{v}_B
$$

<div className="figure-pair">
  <Figure src="images/Fig3-11.jpg" alt="求 p 相对坐标系 B 的坐标" figureNumber="图 3.11" caption="求 p 相对坐标系 B 的坐标（几何图解）。" />
  <Figure src="images/Fig3-12.jpg" alt="求 p 相对坐标系 B 的坐标（另一种情形）" figureNumber="图 3.12" caption="求 p 相对坐标系 B 的坐标（另一种情形）。" />
</div>

<p>推广到 3D 就是 p<sub>B</sub> = x·u<sub>B</sub> + y·v<sub>B</sub> + z·w<sub>B</sub>。<b>因为向量没有位置，这里不需要减原点。</b></p>

<h3>点</h3>

<p>点有位置，所以要多一步：先把 p 减掉 B 的原点，再做投影。这就是点与向量在坐标系变换上的差别。</p>

<h3>逆与坐标系变换矩阵</h3>

<p>如果 M 把坐标系 A 映射到 B，那么 M⁻¹ 把 B 映射回 A。</p>

<div className="figure-pair">
  <Figure src="images/Fig3-13.jpg" alt="M 把 A 映射到 B，M⁻¹ 从 B 映射回 A" figureNumber="图 3.13" caption="M 把坐标系 A 映射到 B，M⁻¹ 从 B 映射回 A。" />

</div>

using namespace DirectX;

XMMATRIX S = XMMatrixScaling(0.5f, 2.0f, 1.0f);
XMMATRIX R = XMMatrixRotationZ(XMConvertToRadians(45.0f));
XMMATRIX T = XMMatrixTranslation(3.0f, 1.0f, 0.0f);

// 行向量：先 S，再 R，最后 T
XMMATRIX world = S * R * T;

// 点：w = 1，会被平移影响
XMVECTOR p = XMVectorSet(0.0f, 1.25f, 0.0f, 1.0f);
XMVECTOR pWorld = XMVector4Transform(p, world);

// 方向：w = 0，不受平移影响
XMVECTOR dir = XMVectorSet(0.0f, 1.0f, 0.0f, 0.0f);
XMVECTOR dirWorld = XMVector4Transform(dir, world);

// 坐标系变换：把世界坐标送回本地，用世界矩阵的逆
XMMATRIX worldInv = XMMatrixInverse(nullptr, world);
XMVECTOR pLocal = XMVector4Transform(pWorld, worldInv);`}

<section className="lesson-section" id="s37">
<h2>本章小结</h2>

<ul>
  <li>线性变换满足 τ(u+v) = τ(u)+τ(v) 与 τ(ku) = kτ(u)，不改变原点；缩放和旋转是线性的，平移不是。</li>
  <li>仿射变换 = 线性变换 + 平移。用齐次坐标（w = 1 是点、w = 0 是方向）才能把平移写进矩阵。</li>
  <li>仿射矩阵的行有几何含义：结果是原矩阵行向量的线性组合，最后一行（行向量约定）承载平移量。</li>
  <li>利用结合律可以把一串变换预乘成一个矩阵 C，大幅减少向量矩阵乘法次数；但<b>交换律不成立</b>，顺序不能换。</li>
  <li>标准顺序是 <b>S · R · T</b>（先缩放、再旋转、最后平移）。</li>
  <li>坐标系变换不改变几何，只改变参考系。向量的公式是 p<sub>B</sub> = x·u<sub>B</sub> + y·v<sub>B</sub> + z·w<sub>B</sub>；点还要先减去 B 的原点。</li>
  <li>变换矩阵与坐标系变换矩阵互为逆：M 把 A 映射到 B，M⁻¹ 把 B 映射回 A。</li>
  <li>代码里用 <code>XMVector4Transform</code> 并显式给出 w：点用 1、方向用 0。</li>
</ul>
