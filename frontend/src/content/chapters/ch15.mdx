<div className="math-block">gView = XMMatrixLookAtLH(eye, focus, up)<small>z 轴 = normalize(focus − eye)；x 轴 = normalize(cross(up, z))；最后一行放 −eye</small></div>

<Callout tone="tip">
  <b>矩阵里能读出相机轴</b>
  <p>视图矩阵前三行（行向量约定下是前三个行向量）正是相机 right / up / look 三条轴在世界坐标中的方向描述。想做「屏幕空间特效」或调试时，可以直接把相机轴画出来。</p>

<section className="lesson-section" id="s152">
<h2>15.2 Camera 类</h2>

<p>相机类需要维护三类状态：位置（<code>mPos</code>）、一组基轴（<code>mRight</code>、<code>mUp</code>、<code>mLook</code>）、以及偏航俯仰角（<code>mYawPitch</code>）。</p>

<p>关键设计是<b>不用三角函数矩阵</b>：移动时直接用基轴当作坐标系，旋转时先旋转基轴。这样每帧只有少量向量运算。</p>

<CodeSample
  title="更新相机基轴"
  language="cpp"
  code={`void Camera::UpdateCameraVectors()
{
    // 偏航角绕世界 y 轴；俯仰角只在水平面前转动
    XMVECTOR cp = XMVectorCos(mYawPitch.x);   // cos(pitch), cos(yaw)
    XMVECTOR sp = XMVectorSin(mYawPitch.x);   // sin(pitch), sin(yaw)

    XMVECTOR look = XMVectorSet(cp.y * sp.x, -sp.y, cp.x * sp.x, 0.0f);
    mLook = XMVector3Normalize(look);

    XMVECTOR right = XMVector3Normalize(XMVector3Cross(mUp, mLook));
    mRight = right;

    // 用重建后的 up 更新上向量
    mUp = XMVector3Cross(mLook, mRight);
}

DirectX::XMMATRIX Camera::GetView() const
{
    XMVECTOR eye = XMVectorSet(mPos.x, mPos.y, mPos.z, 0.0f);
    XMVECTOR lookAt = XMVectorAdd(eye, mLook, 0.0f);
    return XMMatrixLookAtLH(eye, lookAt, mUp);
}`}
  input={<>当前偏航俯仰角 <code>mYawPitch</code> 与位置 <code>mPos</code>。</>}
  keyLines={[
    { code: 'XMVectorSet(cp.y * sp.x, -sp.y, cp.x * sp.x, 0)', note: '偏航绕 y 轴、俯仰只绕水平面前旋转，保证「抬头时不会翻滚」。' },
    { code: 'XMVector3Cross(mUp, mLook)', note: '用叉乘从 look 推出 right，避免累积误差。' },
    { code: 'mUp = XMVector3Cross(mLook, mRight)', note: '上向量用重建结果，可以消除长期累加的漂移。' },
  ]}
  output={<>每帧得到一份 <code>gView</code>，与投影矩阵相乘就是视投影矩阵。</>}
  pitfalls={[
    '每帧直接用 sin/cos 构造旋转矩阵再累乘：会累积漂移，相机长时间运行会歪。',
    '忘记归一化 mLook：移动速度会随时间变化。',
    '俯仰角没有限制在 ±90°：会翻转，矩阵失去意义。',
  ]}

<section className="lesson-section" id="s153">
<h2>15.3 关键方法实现</h2>

<ul>
  <li><code>GetView()</code>：用当前 eye 与 look 调 <code>XMMatrixLookAtLH</code>。</li>
  <li><code>GetWorld()</code>：视图矩阵的逆——拾取（第 17 章）要用它把射线送回世界空间。</li>
  <li><code>Walk(d)</code>：沿 mLook 前进 d。</li>
  <li><code>Strafe(d)</code>：沿 mRight 平移 d。</li>
  <li><code>UpdateCameraVectors()</code>：移动或旋转后重建基轴。</li>
</ul>

<Callout tone="warning">
  <b>视图矩阵的逆就是相机世界矩阵</b>
  <p>相机的 right、up、look 轴彼此正交且已归一化，因此可以利用这个结构构造逆矩阵（旋转部分取转置，并正确处理平移）。若手头只有 view 矩阵，也可调用 <code>XMMatrixInverse(nullptr, view)</code>；通用求逆不一定比利用相机基轴更快。拾取等操作会用到相机世界矩阵。</p>
</Callout>
</section>

<section className="lesson-section" id="s156">
<h2>本章小结</h2>

<ul>
  <li>视图变换把相机放到原点、沿 +z 观察；视图矩阵的行向量就是相机三轴在世界中的描述。</li>
  <li>相机类维护位置、基轴与偏航俯仰；靠基轴移动、用叉乘重建，避免三角函数矩阵累乘的漂移。</li>
  <li>俯仰要限制在 ±90°，并且只在水平面前旋转，防止翻转与翻滚。</li>
  <li>视图矩阵的逆就是相机世界矩阵，拾取与法线变换都要用。</li>
  <li>动态索引用纹理数组 + 实例索引，一次绑定即可让不同实例用不同材质。</li>
</ul>
