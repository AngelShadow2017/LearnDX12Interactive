<h2>9.4 创建并启用纹理</h2>

<p>D3D12 里创建纹理的流程比 D3D11 长：先把图片数据读进上传堆，再用 <code>CopyTextureRegion</code> 拷到默认堆，最后在 SRV 描述符堆里建一个着色器资源视图并绑到根签名。</p>

<CodeSample
  title="创建纹理的两步走"
  language="cpp"
  code={`// 1) 读图片并上传到默认堆
auto woodCrate = std::make_unique<Texture>();
woodCrate->Name = "WoodCrateTex";
ThrowIfFailed(DirectX::CreateDDSTextureFromFile12(device.Get(),
    commandList.Get(), L"Textures\\\\WoodCrate01.dds",
    woodCrate->Resource, woodCrate->UploadHeap));

// 2) 在 SRV 堆里建视图
D3D12_SHADER_RESOURCE_VIEW_DESC srvDesc = {};
srvDesc.Shader4ComponentMapping = D3D12_DEFAULT_SHADER_4_COMPONENT_MAPPING;
srvDesc.Format = woodCrate->Resource->GetDesc().Format;
srvDesc.ViewDimension = D3D12_SRV_DIMENSION_TEXTURE2D;
srvDesc.Texture2D.MipLevels = woodCrate->Resource->GetDesc().MipLevels;
device->CreateShaderResourceView(woodCrate->Resource.Get(), &srvDesc, cpuSrvHandle);

// 3) 绘制前绑定到根签名的描述符表
commandList->SetGraphicsRootDescriptorTable(0, gpuSrvHandle);`}
  input={<>一个已包含所需 mip 级别的 .dds 文件，以及一个 CBV/SRV/UAV 描述符堆。</>}
  keyLines={[

    { code: 'Shader4ComponentMapping', note: '决定 RGBA 通道如何重排；用默认值即可，改错会导致颜色通道互换。' },
    { code: 'SetGraphicsRootDescriptorTable(0, gpuSrvHandle)', note: 'GPU 句柄，不是 CPU 句柄。传 CPU 句柄是 D3D12 新手高频错误。' },
  ]}
  output={<>图 9.1：Crate 演示里贴好木箱纹理的立方体。</>}
  pitfalls={[
    '把 CPU 描述符句柄当 GPU 句柄传：要用 GetGPUDescriptorHandleForHeapStart 取 GPU 侧。',

    '描述符堆没设为 SHADER_VISIBLE：CBV/SRV/UAV 堆必须是 shader visible 才能被着色器看到。',

<section className="lesson-section" id="s97">
<h2>9.7 采样器</h2>

<p>过滤器和寻址模式不写在纹理上，而是写在<b>采样器</b>（<code>D3D12_SAMPLER_DESC</code>）里，绑定在根签名的采样器描述符表（或静态采样器）上。同一个纹理配不同采样器，可以采样出一软一硬两种效果。</p>

<Callout tone="tip">
  <b>静态采样器</b>
  <p>如果一组采样状态全程不变，可以在根签名里声明成静态采样器（<code>D3D12_STATIC_SAMPLER_DESC</code>），连描述符堆都省了。</p>
</Callout>
</section>

<h2>9.10 纹理变换</h2>

<p>UV 也可以像顶点一样被矩阵变换：平移、缩放、旋转 UV 就能做出滚动、平铺、旋转纹理的动画。这只需要在常量缓冲里多传一个纹理矩阵，在顶点着色器里乘到 UV 上。</p>

<section className="lesson-section" id="s912">
<h2>本章小结</h2>

<ul>
  <li>纹理坐标 u 沿右、v 沿下，范围 [0, 1]²；D3D 原点在左上角。v 方向反了是最常见的贴图颠倒原因。</li>
  <li>UV 是逐顶点属性，三角形内由重心坐标插值；多个小图可以放进纹理图集。</li>
  <li>D3D12 创建纹理要「上传堆 → CopyTextureRegion → 默认堆」两步，再建 SRV 并绑到描述符表。</li>
  <li>放大用双线性避免块状；缩小用 mipmap 避免闪烁；各向异性过滤处理掠射角。</li>
  <li>寻址模式处理 uv 超界：Wrap 平铺、Clamp 钳边、Mirror 镜像、Border 边框色。</li>
  <li>过滤与寻址属于<b>采样器</b>，不是纹理；不变的状态可以声明成静态采样器。</li>
</ul>
