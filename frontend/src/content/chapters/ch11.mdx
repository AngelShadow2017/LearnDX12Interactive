<h2>11.1 深度/模板格式与清除</h2>

<p>深度与模板通常共用同一个资源，最常见格式是 <code>DXGI_FORMAT_D24_UNORM_S8_UINT</code>：24 位深度 + 8 位模板。清除时可以一次清两者，也可以只清其中一个。</p>

<CodeSample
  title="清除深度与模板"
  language="cpp"
  code={`// 一次清掉深度与模板

    DepthStencilView(),
    D3D12_CLEAR_FLAG_DEPTH | D3D12_CLEAR_FLAG_STENCIL,
    1.0f,   // 深度清成 1.0
    0,      // 模板清成 0
    0, nullptr);`}

<section className="lesson-section" id="s112">
<h2>11.2 模板测试</h2>

<p>模板测试发生在深度测试<b>之前</b>。形式如下：</p>

$$
(\operatorname{StencilRef}\;\&\;\operatorname{StencilReadMask})\;\mathrel{\trianglelefteq}\;(\operatorname{Value}\;\&\;\operatorname{StencilReadMask})
$$

<p className="math-note">Value 是模板缓冲中的当前值；中间的比较关系代表配置的比较函数。测试不通过时，像素片段会被丢弃。</p>

<p>模板测试不通过时，这个片元在输出合并阶段被丢弃，<b>不会写入颜色或深度</b>。像素着色器位于输出合并之前，因此不能据此断言它一定没有执行；但模板值可以限制哪些片元最终写入目标。这正是「倒影不穿墙」的实现方式（图 11.1）。</p>

<Figure src="images/Fig11-1.jpg" alt="骷髅倒影正确显示在镜子里，没有透过砖墙显示" figureNumber="图 11.1" caption="左：骷髅倒影正确显示在镜子里；倒影没有透过砖墙显示——模板把「镜子外」的倒影像素挡住了。" />

<section className="lesson-section" id="s113">
<h2>11.3 描述深度/模板状态</h2>

<p>D3D12 的深度/模板状态写在 PSO 的 <code>D3D12_DEPTH_STENCIL_DESC</code> 里，关键字段：</p>

<ul>
  <li><code>DepthEnable</code> / <code>DepthWriteMask</code> / <code>DepthFunc</code>：深度测试开关、是否写深度、比较函数（默认 LESS）。</li>
  <li><code>StencilEnable</code> / <code>StencilReadMask</code> / <code>StencilWriteMask</code>。</li>
  <li><code>FrontFace</code> / <code>BackFace</code>：正面与背面可以各配一套 <code>StencilFailOp</code>、<code>StencilDepthFailOp</code>、<code>StencilPassOp</code>、<code>StencilFunc</code>。</li>
</ul>

<Callout tone="tip">
  <b>「只写模板不写颜色」怎么配</b>
  <p>把 <code>RenderTargetWriteMask</code> 设为 0、<code>DepthWriteMask</code> 设为 ZERO，同时 <code>StencilEnable = TRUE</code>、<code>StencilFunc = ALWAYS</code>、<code>StencilPassOp = REPLACE</code>。这样只更新模板。</p>
</Callout>
</section>

<Callout tone="note">
  <b>双重混合问题</b>
  <p>阴影用半透明黑色绘制，如果多个三角形投到同一个像素，就会被混合多次，出现图 11.10 那种深色「痘痘」。书里的解决办法是<b>用模板缓冲计数</b>：只有第一次通过的像素才混合。</p>
</Callout>

<section className="lesson-section" id="s116">
<h2>本章小结</h2>

<ul>
  <li>深度与模板共用资源，常见格式 <code>D24_UNORM_S8_UINT</code>；两者可以一起清，也可以只清一个。</li>
  <li>模板测试在深度测试之前；不通过的像素既不写颜色也不写深度。</li>
  <li>深度/模板状态写在 PSO 的 <code>D3D12_DEPTH_STENCIL_DESC</code> 里，正反面可分别配置。</li>
  <li>平面镜四步：画不透明场景 → 写镜面掩码 → 模板测试内画倒影 → 半透明画镜面。</li>
  <li>反射会翻转绕序，倒影那一 pass 必须把剔除方向反过来。</li>
  <li>平面阴影把物体投影到平面；用模板计数可以避免双重混合造成的深色斑点。</li>
</ul>
