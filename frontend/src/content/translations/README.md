# 全书译文录入交接说明

继续处理第 1–6 章前，先阅读 [独立复核记录与返工说明](./REVIEW-CH01-CH06.md)。其中列出的进度状态和图片复核结论来自直接检查 EPUB 原页，不要只依据现有 uncertain 清单。

每次新开会话还必须先读 [会话状态与续传指针](./SESSION-STATE.md) 和 [统一术语表](./TERMINOLOGY.md)。翻译任务按会话续传，不依赖上一个会话的对话记录；每次结束前必须先更新会话状态、章节进度和新增术语，再交付摘要。

本目录存放直接依据 EPUB 原书逐段录入的中文译文。**不要把 `frontend/src/content/source/*.txt` 自动转换或直接翻译成 MDX**：这些提取文本只能辅助查找章节顺序和图片文件名；原书 EPUB 才是逐段翻译和校对的依据。

## 开始每一轮前

先回答并告知用户：你当前是否能读取这个 EPUB 中嵌入的图片，尤其是公式图片？请区分“能读取 EPUB 的文字”和“能看清公式图片”。然后按下面的分支继续，不要因能力不足而停止整章文字录入：

- **可以看清图片：**按阅读顺序遇到公式时读取原图，辨认符号、上下标、矩阵行列和正负号；再用公式前后的变量定义、推导步骤和例题结果核验。上下文无法确认时，不要猜测。
- **无法看清图片，或无法确认读法：**在译文中保留对应图片，加入可放大的 `<Figure>`，并在 `uncertain-images.md` 记录图片和上下文。不要留 `[[IMG ...]]` 文字标记，也不要把猜测写成定论。

## 范围与交付文件

范围：导读、正文第 1–23 章、附录 A–E。版权页、出版信息和索引不录入。

译文必须以原书页面为准，按阅读顺序保留所有正文段落、术语定义、公式推导、例题及计算步骤、图表和图注、代码及代码说明、章节总结、习题和所有子题。不要把内容概括成教学讲解，也不要跳过重复或看似简单的段落。额外解释如果确有必要，必须另起并标明“译者补充”，不能替代或改写原文结论。

交付到：

- `ch01.mdx` … `ch23.mdx`：每章一个文件；先对照并补完已有文件，不要覆盖已录内容。
- `intro.mdx`：导读。
- `appendix.mdx`：按 A、B、C、D、E 顺序收录全部附录。
- `uncertain-images.md`：全书唯一的不确定图片清单。每个批次持续追加，完成后将它的路径交给用户复核。

每个会话只做**一个连续工作单元**：通常是一个小节；若小节很长，就限定连续 2–4 个 EPUB 页面或约 20 个源内容单元（段落、代码段、列表项、图片等），到边界立即保存并交接。不得在同一会话跳到别章，也不得把相隔的源文拼成一个批次。文件统一追加/最小修改，不覆盖已完成段落。

当前哪些小节已翻译、哪些只做过结构检查、哪些待逐段核验，以 `SESSION-STATE.md` 的队列和 `REVIEW-CH01-CH06.md` 的审计边界为准。不要沿用旧对话或旧 README 中没有在当前文件确认过的断言；已有译文不等于已校对，章节标题覆盖也不等于正文完整。

## 新会话续传协议（必须执行）

### 会话开始

1. 先读 `SESSION-STATE.md`、`TERMINOLOGY.md`、本文件，以及状态文件指定的复核文档和 MDX 文件；用 EPUB HTML 找到确切断点。不能只相信状态文件的一句话，要用当前文件和源文确认。
2. 对照任务范围确认本轮唯一工作单元及其边界。若会话上下文里有用户新指令，按新指令更新状态文件，再继续独立可做的工作。
3. 对译名先查 `TERMINOLOGY.md`。若遇到未收录术语，在本轮局部笔记中记录候选译法和上下文；确认前沿用最贴近现有章节的写法，不要一处多译。

### 会话结束或上下文即将用尽

先把工作写入仓库，再回复用户；不可只在聊天里留下续传摘要。至少更新：

1. `SESSION-STATE.md`：状态、完成范围、下一个源文定位、剩余工作队列、阻塞项和验证结果。
2. 本轮章节的章节台账（暂统一写在 `SESSION-STATE.md` 的章节矩阵中）：小节状态、最后完成的源内容单元、各类内容的覆盖数/待办数、未决图片路径。
3. `TERMINOLOGY.md`：确认的新译名及适用范围；有修改时记录旧译法到新译法及受影响章节，禁止静默变更术语。
4. `uncertain-images.md`：本轮新发现的每个不确定资源；原有项目保留并更新状态，不删除历史记录。

交接指针必须能让一个没有旧对话的模型直接定位到**源 EPUB 的文件、小节、页码、列表/段落/代码/图片类型和可搜索的开头短语**，并指出在目标 MDX 中应从哪里继续。若尚无稳定页码，就同时给源块顺序号和开头短语。交接摘要不能写“继续第 X 章”这种不足以续传的指示。

### 建议的会话记录字段

```text
会话日期 / 执行者：
工作类型：录入 / 原文复核 / 修订 / 公式识图
本轮唯一范围：
源文件与断点：文件；页码；小节；源块类型与序号；开头短语
目标文件与插入点：
本轮完成：
本轮核验数字：正文块 __/__；代码块 __/__；列表项 __/__；图片 __/__；习题 __/__
图片去向：已转 LaTeX / 保留 Figure / 新增 uncertain（列路径）
术语决定：新增或沿用哪些术语；改动范围
未完成 / 有疑问：
验证：运行了什么命令及结果；未能运行的原因
下一轮唯一任务：精确到源文件、小节、页码、类型、序号和开头短语
```

百分比或“基本完成”不能替代上述具体计数；未实际对照 EPUB 的内容标为“已录入待核”，不要标为“已核验”。

## MDX 与图片规则

- 章节小节使用对应目录中的锚点 ID，例如 `s31`、`s32`。导读沿用 `start-goals`、`start-background`、`start-tools`、`start-route`；附录沿用 `appendix-a` 至 `appendix-e`。
- 行内公式使用 `$...$`，独立公式使用 `$$...$$`。只有经识图且通过上下文校验的公式图片才转成 LaTeX。
- 独立插图使用：

  ```mdx
  <Figure src="images/Fig3-1.jpg" alt="用中文准确描述图意" figureNumber="图 3.1" caption="翻译后的原书图注。" />
  ```

- 图片路径必须写成相对路径 `images/文件名.jpg`，不能以 `/` 开头。文件名大小写必须与 `images/` 中的真实文件名一致。
- 无法确认的公式图放在对应文字旁边，并登记到 `uncertain-images.md`，记录章节/小节、EPUB 页码（能确定时）、周围句子、`images/` 路径、EPUB 内部路径（能确定时）、不确定状态和原因。矩阵数据、符号或符号方向看不清时，也按不确定处理。
- 代码按原文抄录，保留大小写、标点、宏、函数签名、输出和紧邻解释，使用带语言标记的 fenced code block（例如 ` ```cpp `）。不要只保留摘要或链接。
- 图像公式不在 MDX 正文中显示时，不能只登记文件名：仍须在原位置放可见图片，保证译文没有内容空洞。
- 不要把模板文件纳入章节 glob；章节模板位于 `translation-parts/chapter-template.mdx`，它只是复制参考。

## 章节结束前自检

1. 对照 EPUB 的目录和页面顺序逐项核对：标题、每个小节、段落、定义、证明、例题、代码、图表图注、总结、习题编号及子题均已处理。
2. 全文搜索 `[[IMG`，译文中不得残留提取标记。
3. 每张公式图片都应是已确认的 LaTeX，或仍显示为可放大的原图且列在不确定清单；不允许静默遗漏或猜公式。
4. 核对所有 `images/...` 文件存在且路径大小写正确；禁止绝对 `/images/...` 路径。
5. 每章同时完成两项独立核验，并在复核记录中分别标状态：
   - **术语一致性：**运行 `npm run check:translation-terms`，再检查新增术语是否应补入 `TERMINOLOGY.md`。脚本通过不代表正文忠实度已通过。
   - **原文忠实度：**按 EPUB 顺序逐段对照中文说明、定义、推导、例题讲解、图注、总结和全部习题题干/子题；检查遗漏、增义、反义、数值和变量名错误。发现原书自身错误时照录并加“译者注”，不要把它误记为译文错误。
6. 完成一批后运行 `npm run build`、`npm test` 和 `npm run check:translations`。全书文件齐备后运行 `npm run check:translations:complete`。
7. 不使用截图或远程操控浏览器。可直接阅读 EPUB 文件及其图片资源。

## 可直接交给复制模型的开场指令

> 请先告诉我：你能否读取我提供的 EPUB 中的图片并可靠辨认公式？然后以 EPUB 页面为唯一翻译依据，逐章逐段制作完整中文译文；不要从提取 TXT 批量转换或概括。保留每一段原文信息、推导、例题、代码及说明、图注、总结和全部习题。能识图时，只把已识别且与上下文核实一致的公式图片转为 LaTeX；不能识别或不能确认时，原位保留 `<Figure>` 并把路径与上下文追加到 `uncertain-images.md`。按本说明中的文件名、锚点和 MDX 格式录入，一次完成一章；每批交付时列出完成范围、确认公式映射和待复核图片。

## 每个新会话使用的续传提示

每次重开会话时，把下面这段发给复制模型。模型应从仓库状态恢复任务，不要要求用户重新讲一遍项目背景：

> 这是一个新会话。请先读取 `frontend/src/content/translations/SESSION-STATE.md`、`TERMINOLOGY.md`、`README.md`，以及状态文件指定的复核记录、EPUB 源文件和目标 MDX。先用当前文件与 EPUB 确认状态中的精确断点，并告诉我你能否读取 EPUB 图片、能否辨认小字号公式。然后只执行状态文件中“下一会话的唯一任务”，以 `.epub/OEBPS/*.html` 为唯一翻译依据；遵守术语表，不能确定的公式原位保留可放大图片并更新 `uncertain-images.md`。请直接修改并保存仓库文件。结束前更新 `SESSION-STATE.md` 中的断点、完成计数、未决图片、术语变更、验证结果和下一轮唯一任务；聊天摘要不能替代文件记录。不要截图或使用远程操控浏览器。若本会话因长度将结束，请先保存这些记录，再停止当前批次。
