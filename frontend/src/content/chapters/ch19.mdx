<section className="lesson-section" id="s192">
<h2>19.2 法线图</h2>

<p>法线图和普通颜色贴图一样是 RGB 纹理，只是每个像素编码了一条<b>法线</b>。常见 8 位格式先把法线的 [−1, 1] 分量映射到 [0, 1] 存进 RGB；采样后要做 <code>2·c − 1</code>，才能还原到 [−1, 1]。</p>

<p>关键点：这条法线是<b>相对表面</b>的，不是相对世界坐标系的（图 19.3）。</p>

<Figure src="images/Fig19-3.jpg" alt="法线图中的法线相对切线空间存储" figureNumber="图 19.3" caption="法线图中的法线相对切线空间（T 为 u 轴、B 为 v 轴、N 为法线）存储。" />

<Callout tone="tip">
  <b>原书示例把 alpha 用作光泽度遮罩</b>
  <p>RGB 用于解码法线，alpha 则单独存逐像素 shininess：白色表示 1、黑色表示 0（图 19.7）。把 alpha 改存其他标量属于资源打包方案的选择，不是本书示例的设置。</p>
</Callout>

<Figure src="images/Fig19-7.jpg" alt="地砖法线图的 alpha 通道表示光泽度" figureNumber="图 19.7" caption="地砖法线图的 alpha 通道：alpha 值表示该处的光泽度。" />
</section>

<section className="lesson-section" id="s193">
<h2>19.3 纹理/切线空间</h2>

<p>为了让「相对表面」变得明确，每个顶点要带一组<b>切线空间</b>基向量（图 19.4）：</p>

<ul>
  <li><b>T（切线）</b>：沿纹理 u 方向；</li>
  <li><b>B（双切线）</b>：沿纹理 v 方向；本书在正交基中用 <code>B = cross(N, T)</code> 重建；</li>
  <li><b>N（法线）</b>：几何法线。</li>
</ul>

<section className="lesson-section" id="s194">
<h2>19.4 顶点切线空间</h2>

<p>由于每个面的切线空间都不同（图 19.5），切线 T 必须作为<b>逐顶点属性</b>存进顶点缓冲。原书的顶点着色器把几何法线 N 和切线 T 变换到世界空间后传给像素着色器；像素着色器在插值后重新正交化 T，再构造 TBN 基。</p>

<Callout tone="warning">
  <b>工程补充：镜像 UV 的手性</b>
  <p>原书的示例网格直接用 <code>cross(N, T)</code> 重建 B。对带镜像 UV 的通用网格，切线基可能翻转；可将 UV 导出的副切线 B 与 <code>cross(N, T)</code> 比较，以 <code>sign(dot(cross(N, T), B))</code> 保存手性，并在重建时乘回该符号。</p>
</Callout>
</section>

<section className="lesson-section" id="s195">
<h2>19.5 切线空间与物体空间</h2>

<p>贴图法线 $(x,y,z)$ 的三个分量分别表示沿切线 $T$、双切线 $B$、几何法线 $N$ 的偏移。把它还原到世界空间，就是按这三个方向做线性组合：</p>

$$
\mathbf{n}_W=
\begin{bmatrix}x&y&z\end{bmatrix}
\begin{bmatrix}
T_x&T_y&T_z\\
B_x&B_y&B_z\\
N_x&N_y&N_z
\end{bmatrix}
=x\mathbf{T}+y\mathbf{B}+z\mathbf{N}.
$$

<p>行向量约定下，矩阵的三行就是世界空间的 T、B、N；因此样本的 x 分量沿 T 走，y 分量沿 B 走，z 分量沿 N 走。原书先把 T 对 N 正交化，再构造 TBN 基。</p>

<p>图 19.6 说明 T 里平行于 N 的分量必须先减掉（正交化），否则组合出来的法线不严格垂直于表面。</p>

<Figure src="images/Fig19-6.jpg" alt="由 ‖N‖=1 得 projN(T)=(T·N)N，正交化示意" figureNumber="图 19.6" caption="由 ‖N‖=1 得 projN(T)=(T·N)N；T−projN(T) 是 T 中垂直于 N 的分量（正交化）。" />

$$
\mathbf{T}_{\perp}=\mathbf{T}-(\mathbf{T}\cdot\mathbf{N})\mathbf{N},\qquad
\mathbf{T}'=\operatorname{normalize}(\mathbf{T}_{\perp}),\qquad
\mathbf{B}=\mathbf{N}\times\mathbf{T}'.
$$

<p>这里假设 <code>N</code> 已归一化；若它不是单位向量，投影系数还要除以 <code>N·N</code>。正交化后 T 与 N 垂直，叉积得到同时垂直于两者的 B，于是三条互相垂直的基轴完整确定。</p>

<section className="lesson-section" id="s196">
<h2>19.6 法线贴图着色器代码</h2>

<p>下面保留原书的解包、正交化和 TBN 变换流程，并显式归一化插值后的几何法线与输出法线：纹理过滤会把多个 texel 混在一起，插值向量的长度可能不再是 1。</p>

<CodeSample
  title="法线贴图变换（原书流程，显式归一化输出）"
  language="hlsl"
  code={`struct VertexOut
{
    float4 PosH : SV_POSITION;
    float2 TexC : TEXCOORD;
    float3 NormalW : NORMAL;
    float3 TangentW : TANGENT;
};

float3 NormalSampleToWorldSpace(float3 sample, float3 normalW, float3 tangentW)
{
    float3 normalT = 2.0f * sample - 1.0f;
    float3 N = normalize(normalW);
    float3 T = normalize(tangentW - dot(tangentW, N) * N);
    float3 B = cross(N, T);
    float3x3 TBN = float3x3(T, B, N);
    return normalize(mul(normalT, TBN));
}

float4 PS(VertexOut pin) : SV_Target
{
    float3 sample = gNormalMap.Sample(gSampler, pin.TexC).rgb;
    float3 bumpedNormalW = NormalSampleToWorldSpace(sample, pin.NormalW, pin.TangentW);
    // 本行用伪彩色显示法线；原书将 bumpedNormalW 用于光照和环境贴图反射。
    return float4(bumpedNormalW * 0.5f + 0.5f, 1.0f);
}`}
  input={<>一张切线空间法线贴图，以及逐顶点的 N / T。</>}
  keyLines={[
    { code: 'float3 normalT = 2.0f * sample - 1.0f', note: '解包：[0,1] → [−1,1]。漏掉这步，法线全都偏向 (0,0,1)。' },
    { code: 'N = normalize(normalW)', note: '像素着色器插值会让顶点单位法线长度偏离 1，因此先归一化再构造切线基。' },
    { code: 'T = normalize(tangentW - dot(tangentW, N) * N)', note: 'Gram–Schmidt 正交化，去掉 T 沿 N 的分量。' },
    { code: 'normalize(mul(normalT, TBN))', note: '按行向量约定把切线空间法线变换到世界空间；归一化也补偿纹理过滤造成的长度变化。' },
  ]}
  output={<>几何完全没变，但表面出现凹凸细节，高光也随之碎裂。</>}
  pitfalls={[
    '忘记解包 2·c−1：凹凸方向整体偏移，画面像「贴反了」。',
    'T 没有逐顶点传入：整个网格共用一条切线，弯曲表面上会明显出错。',
  ]}
/>

<Callout tone="note">
  <b>教学扩展：法线强度</b>
  <p>原书的法线变换函数没有强度参数，也没有这张合成纹理交互。交互用正弦高度场的梯度生成法线，再额外缩放切线空间 x/y 分量，帮助观察法线偏离平面几何后高光如何变化。</p>
</Callout>

<section className="lesson-section" id="s197">
<h2>本章小结</h2>

<ul>
  <li>法线贴图不移动任何顶点，只扰动光照使用的法线——用一张 2D 纹理换来源表面细节。</li>
  <li>RGB 以 [0,1] 编码切线空间法线，采样后先用 <code>2·c−1</code> 解包。</li>
  <li>每个顶点要带切线 T（沿 u）；本书用 B = cross(N, T) 构造切线空间基。</li>
  <li>还原到世界空间：<code>n = normalize(T·x + B·y + N·z)</code>；T 需先正交化。</li>
  <li>工程补充：镜像 UV 的通用网格可额外携带手性标志；本页交互的法线强度滑块也是教学扩展，数值过大时会使高光与几何细节不协调。</li>
</ul>
