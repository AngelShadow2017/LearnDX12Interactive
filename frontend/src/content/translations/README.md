# 全书译文录入交接说明

本目录存放直接依据 EPUB 原书逐段录入的中文译文。**不要把 `frontend/src/content/source/*.txt` 自动转换或直接翻译成 MDX**：这些提取文本只能辅助查找章节顺序和图片文件名；原书 EPUB 才是逐段翻译和校对的依据。

## 开始每一轮前

先回答并告知用户：你当前是否能读取这个 EPUB 中嵌入的图片，尤其是公式图片？请区分“能读取 EPUB 的文字”和“能看清公式图片”。然后按下面的分支继续，不要因能力不足而停止整章文字录入：

- **可以看清图片：**按阅读顺序遇到公式时读取原图，辨认符号、上下标、矩阵行列和正负号；再用公式前后的变量定义、推导步骤和例题结果核验。上下文无法确认时，不要猜测。
- **无法看清图片，或无法确认读法：**在译文中保留对应图片，加入可放大的 `<Figure>`，并在 `uncertain-images.md` 记录图片和上下文。不要留 `[[IMG ...]]` 文字标记，也不要把猜测写成定论。

## 范围与交付文件

范围：导读、正文第 1–23 章、附录 A–E。版权页、出版信息和索引不录入。

译文必须以原书页面为准，按阅读顺序保留所有正文段落、术语定义、公式推导、例题及计算步骤、图表和图注、代码及代码说明、章节总结、习题和所有子题。不要把内容概括成教学讲解，也不要跳过重复或看似简单的段落。额外解释如果确有必要，必须另起并标明“译者补充”，不能替代或改写原文结论。

交付到：

- `ch01.mdx` … `ch23.mdx`：每章一个文件；先对照并补完已有文件，不要覆盖已录内容。
- `intro.mdx`：导读。
- `appendix.mdx`：按 A、B、C、D、E 顺序收录全部附录。
- `uncertain-images.md`：全书唯一的不确定图片清单。每个批次持续追加，完成后将它的路径交给用户复核。

一次只处理一章；章节过长时按连续小节分批追加到该章同一个 MDX 文件。每批结束时汇报文件名、已完成小节、确认过的公式图片及 LaTeX、待复核图片路径。不要用新输出覆盖此前已完成的小节。

现有第 1、2 章只是待校对的首轮稿，不代表已通过原书逐页核验。必须从 EPUB 重新按段落顺序检查它们，并在原文件中补全或修订，不要因为目标文件已存在就跳过。第 1 章的 DirectXMath 示例代码有几处目前只提供“切换到原文查看”的链接，代码并未出现在译文里；请将对应原书代码原样补入代码块，也检查第 1 章习题 19 的程序是否完整。第 2 章的内联数学标记曾有格式问题，须逐式检查 `$...$` / `$$...$$` 是否完整，尤其检查矩阵乘积逆的证明。

## MDX 与图片规则

- 章节小节使用对应目录中的锚点 ID，例如 `s31`、`s32`。导读沿用 `start-goals`、`start-background`、`start-tools`、`start-route`；附录沿用 `appendix-a` 至 `appendix-e`。
- 行内公式使用 `$...$`，独立公式使用 `$$...$$`。只有经识图且通过上下文校验的公式图片才转成 LaTeX。
- 独立插图使用：

  ```mdx
  <Figure src="images/Fig3-1.jpg" alt="用中文准确描述图意" figureNumber="图 3.1" caption="翻译后的原书图注。" />
  ```

- 图片路径必须写成相对路径 `images/文件名.jpg`，不能以 `/` 开头。文件名大小写必须与 `images/` 中的真实文件名一致。
- 无法确认的公式图放在对应文字旁边，并登记到 `uncertain-images.md`，记录章节/小节、EPUB 页码（能确定时）、周围句子、`images/` 路径、EPUB 内部路径（能确定时）、不确定状态和原因。矩阵数据、符号或符号方向看不清时，也按不确定处理。
- 代码按原文抄录，保留大小写、标点、宏、函数签名、输出和紧邻解释，使用带语言标记的 fenced code block（例如 ` ```cpp `）。不要只保留摘要或链接。
- 图像公式不在 MDX 正文中显示时，不能只登记文件名：仍须在原位置放可见图片，保证译文没有内容空洞。
- 不要把模板文件纳入章节 glob；章节模板位于 `translation-parts/chapter-template.mdx`，它只是复制参考。

## 章节结束前自检

1. 对照 EPUB 的目录和页面顺序逐项核对：标题、每个小节、段落、定义、证明、例题、代码、图表图注、总结、习题编号及子题均已处理。
2. 全文搜索 `[[IMG`，译文中不得残留提取标记。
3. 每张公式图片都应是已确认的 LaTeX，或仍显示为可放大的原图且列在不确定清单；不允许静默遗漏或猜公式。
4. 核对所有 `images/...` 文件存在且路径大小写正确；禁止绝对 `/images/...` 路径。
5. 完成一批后运行 `npm run build`、`npm test` 和 `npm run check:translations`。全书文件齐备后运行 `npm run check:translations:complete`。
6. 不使用截图或远程操控浏览器。可直接阅读 EPUB 文件及其图片资源。

## 可直接交给复制模型的开场指令

> 请先告诉我：你能否读取我提供的 EPUB 中的图片并可靠辨认公式？然后以 EPUB 页面为唯一翻译依据，逐章逐段制作完整中文译文；不要从提取 TXT 批量转换或概括。保留每一段原文信息、推导、例题、代码及说明、图注、总结和全部习题。能识图时，只把已识别且与上下文核实一致的公式图片转为 LaTeX；不能识别或不能确认时，原位保留 `<Figure>` 并把路径与上下文追加到 `uncertain-images.md`。按本说明中的文件名、锚点和 MDX 格式录入，一次完成一章；每批交付时列出完成范围、确认公式映射和待复核图片。
